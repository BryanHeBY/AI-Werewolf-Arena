# LLM User Prompt 三行高密度规范

## 背景

为降低提示词漂移风险，行动前 `user prompt` 改为三行自然语言高密度格式。
该规范目标是减少上下文噪声，将失败归因更多收敛到模型能力本身，而非提示工程复杂度。

## 目标

1. 每次行动前 `user prompt` 固定为三行，不使用 `key=value` 结构。
2. 明确输出发言轮次状态文案：
   - `目前是你的发言轮次。`
   - `目前不是你的发言轮次。`
3. 保留最小可执行信息：
   - 当前阶段与子阶段
   - 回合约束要求（`turn_constraints`）
   - 可用工具列表
   - 工具参数提示

## 三行模板

```text
[行动提示] {actorId}号玩家，现在轮到你行动，当前处于{phase}阶段，子阶段是{stage}，{目前是你的发言轮次|目前不是你的发言轮次}。
{你本轮必须至少调用一次可用工具完成行动。|你本轮可以选择结束回合不行动。} 你当前可以使用的工具有：{toolList}。
工具参数提示：{toolArgHints}。请直接调用工具完成本轮行动。
```

## 规则说明

1. 发言轮次判定：
   - 若本轮可用工具包含 `speak` 或 `speak_to_wolves`，判定为“是你的发言轮次”。
   - 其他情况判定为“不是你的发言轮次”。
2. 回合约束文案：
   - 优先渲染结构化 `turn_constraints`（最少/最多动作次数、必需工具命中要求）。
   - 若未提供 `turn_constraints`，兼容旧字段 `must_act`：
     - `mustAct=true` -> 至少一次有效行动；
     - `mustAct=false` -> 可零行动结束。
3. `finish_turn`：
   - 可在任意阶段暴露给模型；
   - 是否允许真正结束由约束判定层决定，不满足约束时必须返回结构化拒绝并继续当前回合。
4. 保持 system prompt 现有硬约束不变（工具调用、禁止思维链、阶段职责等）。
5. 当可用工具为 `self_destruct` 时，system prompt 必须包含醒目警告：`自爆需谨慎！！！`。

## 验收标准

1. `LLM_IO` 中每次 `prompt_user` 为严格三行，且文案符合模板。
2. 发言阶段（白天发言/狼人夜聊）显示“目前是你的发言轮次”。
3. 非发言阶段（投票、查验、守护、用药等）显示“目前不是你的发言轮次”。
4. `build:v3` 与 `tests/v3` 全量通过。
