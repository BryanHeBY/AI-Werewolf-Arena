# 玩家提示机制说明归属

本批把玩家状态说明、阶段规则说明、绑定能力所用的规则角色、动物板子熊的技能简介，以及 N+2 初始身份附注归到游戏观察模块。SDK／ACP 共用策略继续组织模板、人设、工具协议提示与开局公开配比缓存。

## 所有权与时点

机制说明分别读取玩家历史知识、关系、当前自持能力和枪的摘要；已知日志不替代真实库存，文字候选也不授予行动许可。查询按原表达式位置执行，保留 World、语言、目录和板子 getter 的读取时点、原接收者与失败前缀。自定义角色 renderer 仍在后段以可选调用执行，没有 renderer 时不提前读取语言。

构造器的公开 Map／size 和唯一初始身份机制查询本批保持，后续独立迁移。AI 模板、人设和传输协议没有归到机制模块。新增结果对象保留原能力及其状态引用；私有 status／stage 方法退休和静态初始化图变化有意存在，仓库内无调用不能证明未知外部反射消费者兼容。

## 验证与审查

- 从当前所有者五段完整业务逻辑与四处真实查询对象逆向重建原策略，完整程序 3,108 个节点保持；十项完整类型语法检查、二十项完整输出 AST 保持。排版差异使其中仅六项 raw bytes、八项 token 保持，不称全部字节相同。
- 123 项原绑定逐一核对归属，局部运行图 343 个模块中，观察所有者不反向依赖 AI 策略或模板。旧策略 37 项实际运行导入变为十项，初始化图变化如实保留。
- 新增六个有界用例、27 个断言通过，覆盖 getter 顺序、第二次板子读取失败、绑定能力引用、目录接收者、角色原文及迟调用失败前缀。三个文件的有限类型检查首次发现新 thunk 缩窄与测试上下文声明问题，仅作类型修复，四项完整输出字节保持；最后实际通过。
- 三个触及文件的真实职责检查无诊断；中文头及知识／库存、候选／许可、晚回调与失败顺序说明就地补齐。Root 阅读实际源码，另一位审查者独立核对完整逻辑、实际基线和最终哈希并批准。
