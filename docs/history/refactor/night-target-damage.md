# 单目标伤害政策边界

本批继续 C26，将原伤害结算中单目标的保护与死因规则归入 `night-damage-target.ts`。结算器按原实体顺序调用它，再追加死亡提案和清理印记；原前置免疫过滤、无效实体跳过与结果返回保持。

目标政策消费只读折叠计划、原效果对象的窄视图和仅含 `has()` 的印记读者。效果视图仅提供四项晚读取的 ID 列表与修饰死亡的原生命只读绑定，不暴露毒源、守护印记或库存。五项类型负例确认这些权限不可获得，原输入仍可直接赋给视图。唯一修改权限为 `cancelOrdinaryProtection()`：在原同守同救分支调用，原 Guard／Heal 两次 `remove()` 留在结算器，使用同一印记 receiver。政策不能添加或清空印记、写生命、发布事件或消费库存。

普通狼刀、机械额外刀、觉醒额外刀、直接毒、反射毒及反噬仍使用各自的原规则。梦境、免疫、连续死亡与修饰效果保持每实体晚读取，死因顺序不变，没有将全部伤害改成同一政策。
