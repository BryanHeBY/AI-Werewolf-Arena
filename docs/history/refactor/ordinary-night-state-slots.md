# 普通预言家、守卫与女巫状态槽

三族完整状态 getter、初始化安装和全部普通／受赠写程序归各自 state-slot，三个旧内部 state 叶删除。实际夜间与 recipient 调用方直接使用 allowedWrites；初始化继续按原 JSON 复制后调用既有完整 prepared-native 库存所有者。资料／运行／展示三贡献不改，三个 profile 只调整相同导入绑定。

预言家受赠报告保持四次 ability.state 和两次 target.id 读取；守卫先捕获左侧状态才读取目标 getter。女巫夜复位先写两个旗标再按原规则短路读取日期；原生减量与受赠 postfix 毒药减量分别保留。Demon 封存控制器及写入没有改，不用普通药瓶规则合并它们。次数、来源、生命、目标和完整租约仍由原调用方／owner 验证。

create／schema 是同一原 JSON 复制函数，不新增 history、资源数或 extra 键拒绝。三个政策身份表达式在原调用点编码，JSON.stringify 查找先于 Seer 两次／Guard 一次／Witch 三次状态读取；归档仍由原 checkpoint 完整克隆，不建立第二状态或 JSON 仓库。

## 验证范围

[证据](generated/ordinary-night-state-slots-evidence.json)记录 26 路径：23 个现 source／test 和三个删除。22 个原来源的真实 Git 字节、104 项完整源检查、19 个完整非 import 程序共 13,529 节点相同；全部消费者绑定保留，六个旧测试只调整导入。

两种模块输出共 38 份，其中 34 份原字节相同；普通安装器／Scope 的四份因合成节点多行标志原字节不同，完整 parser token 相同，不屏蔽字段、数组或断言。局部 27 模块运行图证明三族 state-slot 不反导普通安装器、abilities 不反导三槽、prepared owner 无运行依赖。

新增八个有限用例通过、46 断言，有限 23 个入口类型进程 2639 实际退出码 0。此后只补机制专属中文头与关键读取／写权／失败说明，不重复类型或运行。没有整局、计费模型或全量门禁。
