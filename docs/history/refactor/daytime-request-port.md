这是明确的静态接受面扩大，不声称整个类型树不变。原方法、参数顺序、可选性、三个结果、readonly 成员和异常策略保持，沒有新增运行函数、wrapper、复制、冻结或资源权限。三个窗口实例仍带原 receiver，类型端口不使请求数据获得提交许可。

新增中文接口说明核真实行为：自爆 commit false 继续下一候选，未提供回调时只返回选择；骑士只有有效候选才要求 commit；辩论 skipSpeech 只表达原发言是否跳过，实际密封票／付款／处罚／关闭归其 owner。readonly 限制组合成员重绑定，不冻结实际窗口。
