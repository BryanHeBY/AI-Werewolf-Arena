## 范围与归属

基线为实际 Git `cdbe1cf15c6046f893436c7a39764e10117ef097`。本批四源：修改狼夜阶段，新增 `rulesets/ordinary-wolf-knife-routing.ts`、雾鸦 `knife-ports.ts` 和三个定向单元用例；不删除文件。

## 顺序和失败边界

- 多数决先取 callee，再读原票表；板查询先于空刀短路。只有原雾圈非 null 才检查原票序／弃票数、读取 RNG 两次并调用一次。
- 原圈可以为空；原错误和接受宽度保留，不增加圈成员拒绝或任何新 current 检查。`originalMistTarget` 仍在抽取之后读取 World、日期和目标。
- 抽刀事件先于 `wolfTarget` 写入。随后加成命令、投票者和诊断依次执行；任何异常保留已付款或已写前缀，不退款。
- 原目标生命复验后才调用映射。当前性失败先于印记；`ensureMarks`、`add`、范围 LHS 与两个映射 scope 读取保持原顺序。运行生命／印记引用不是 JSON 或玩家知识。
- 新组合同步返回，不新增等待或 RNG fork。贵族事实发布仍由狼阶段在原末点执行。
