本批为 6 个路径。九个原生产／测试候选的完整运行程序、原数据声明和消耗体核对通过。新增三项测试验证同资源读取、转移归属、首次死亡捕获与到期，以及抛错库存 setter 的原失败前缀，结果为 3 通过、0 失败、20 项断言。原测试的三处损坏状态写入只增加具体字段的类型断言，逆向恢复后整个文件与实际 Git 原字节一致。

源码、共享包浏览器环境及最终后端源码／测试类型检查通过；本批六个文件头及依赖检查没有新增失败。Root 检查实际 owner、调用方、数据和新测试；子代理独立核对真实 Git 声明、原 fixture 与六个最终摘要。详细输入与实际退出结果见[证据](generated/death-gun-state-evidence.json)。没有重跑完整对局、发现或全仓门禁。
