# 显式录制与契约身份

C39／C40 本切片使真实录制、文件执行与复盘展示使用明确版本声明。这是文件格式 API 迁移，不是旧文件字节等价重构。

## 格式与消费

| 档案 | 新写入格式 | 历史读取政策 |
| --- | --- | --- |
| `replay.json` | `awa-recording` envelope 1，公开 payload schema 2 | 未声明／1／2 裸复盘继续原转换与原文政策 |
| `reproduction.json` | envelope 1，严格 Tape schema 2 | 裸 Tape 2 继续原精确执行检查；旧构建默认拒绝 |
| `manifest.json` | 原格式 | 本切片尚未添加显式身份 |
| 玩家视角文件 | 原 schema 2 | 本切片尚未添加 envelope 身份 |

新封装声明档案种类、内层格式、请求契约、展示契约、ruleset 和已捕获的真实构建／RNG 来源。它不是签名或行动许可。未建立 Trace 的初始公开档以 `null` 表示来源缺席；后续原发布时点使用 Trace 实际已捕获元数据。公开声明不包含私有 seed，seed 仍只在原 manifest／Tape。

严格 CLI 保留完整文件输入后再执行，按原次序检查 source／lock、RNG 与 ruleset，其后核对新请求／展示身份及 header 与 payload 的来源一致性。语义版本相同不能放开跨构建复现。前端文件、API 和直接视频输入实际检查展示 owner 的支持范围，未知新版本明确拒绝。

未声明新协议的旧裸档自定义 `format` 扩展继续保留。已知 `awa-recording` 数据标记或自有 `envelopeVersion` 声明新协议；判别只读取属性描述符，不提前执行 getter。声明新协议后，未知 format、外层／内层版本或错误 kind 不能降级解释为历史复盘。

## 状态与失败边界

Trace 仅新增返回已捕获来源副本的数据方法，不重读调用方 getter、liveEvents 或返回原可写元数据。Session 更新身份快照不触发新 dirty／刷盘调度；原三个公开写入、两个严格写入站点、文件数和错误汇总顺序保持。

同笔迁移全部实际磁盘消费者与导出入口。旧测试的期待值、字面样本和断言保留，输入只接入新封装读取。schema 2 reader 返回完整副本，额外字段不会因类型声明变窄而消失；原隐私负例仍检查真实内容。
