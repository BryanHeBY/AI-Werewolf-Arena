# 纯查验政策的公共契约

本批以 `694a2593` 为源码基线，把查验政策的完整纯算法迁入 `@ai-werewolf-arena/game-contract/role-inspection-policy`。五个声明包括角色政策读取、默认政策映射、实际目标政策解释、允许重复判断和必选判断。状态槽继续负责复制、原政策校验、安装、原对象访问和报告历史写入；配置 schema 与本地化标签留在机制内。

## 边界与顺序

显式目标政策优先，会短路角色政策读取；缺省分支才解释角色政策。角色政策读取保留先校验配置、再读取身份政策的顺序、重复 getter 与原机器错误码。默认映射的 `as const` 只约束类型，没有增加运行时冻结。

纯契约不读取 World、历史、生命、库存、阶段或租约，也不授予查验权限。观察与 Agent 可以解释已经获得的政策数据，行动时的目标、付款和有效窗口仍由具体机制复验。旧 `ports`、`policies` 和 `state-slot` 不再转发迁走的查询。
