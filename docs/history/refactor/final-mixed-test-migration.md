本批将最后 17 个原混合测试文件分为 37 个功能入口，覆盖 564 个冻结用例 ID 和 239 个注册节点：单元层 349 个 ID、集成层 37 个 ID、场景层 178 个 ID。分类依据实际执行边界，完整 PhaseManager 或中央死亡链归场景；本地 SDK／MCP 通信、文件归档和公开配置读取归集成；单独策略、许可、回调或被拒绝的重入请求归单元层。

提交按两组拆分：Agent 接收与夜间能力共 7 个来源、12 个目标、157 个 ID；身份、关系与公开事件共 10 个来源、25 个目标、407 个 ID。每个原注册只有一个目标；矩阵、控制祖先和必要 helper 保留原内容及资源分配位置。现有损坏状态的类型适配已属于 `23511ef7` 原始输入，本次迁移没有增加造数或改变断言。

239 个回调中 234 个保持原字节，5 个仅调整精确的模块位置；177 个 helper 中 174 个保持原字节，3 个仅调整公共 URL 或类型路径。原数组成员、空位、顺序和循环保持。动态导入、类型导入及公共 URL 均指向同一实际文件。独立 Root 检查整段选中程序、注册的唯一归属、原始输入与断言，以及实际文件摘要。

删除未使用导入也删除对应的无用加载路径，因此没有声明完整初始化顺序一致。有限加载检查记录实际移除的模块及顶层初始化。Hidden Wolf 的两个新入口分别读取同一个已缓存 catalog，原一次读取变为两次暖缓存读取；没有新增实际 catalog 对象或把测试函数内的 factory 调用算作顶层初始化。必要的装配、钩子、文件读取和资源清理仍保留。

本批的[证据](generated/final-mixed-test-evidence.json) 记录来源、目标、原 ID、层级、加载范围和实际检查结果。针对性类型检查固定迁移前的生产源码，避免将并行生产 API 修改混入测试移动。没有逐笔重跑完整对局、浏览器或发现。
