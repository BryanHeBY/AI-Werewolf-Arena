# 普通角色私有状态的数据与读写边界

本批覆盖猎人、狼王、白狼王、骑士、白痴、熊、守墓人、狼美人、隐狼、石像鬼、机械狼、觉醒隐狼、奇迹商人和黑市商人的实际私有状态入口。

`packages/game-contract/src/role-state-data.ts` 集中原有 24 个数据声明和 20 个有限读取别名。字段顺序、可选值、null、字面量、策略类型和安装输入原有的可写约束保留。包根使用明确的类型出口；数据模块没有 World、许可、解析器、运行存储或玩家裁剪职责。

14 个 getter 返回原对象的只读视图，历史、历史结果、学习数据、模式和交易选择也表达只读约束。原安装函数继续保留各自的引用或复制行为：简单状态存入原输入；机械狼、觉醒隐狼和两种商人沿用原复制。没有冻结资源、产生新的读取对象或增加状态容器。

实际阶段中的写入收归具名功能操作，包括熊的普通吼叫记录、机械狼查验与技能消耗、两种商人的关闭和交易。命令保留原赋值、属性访问和异常前缀：机械狼先读取 history 和 push，再读取 target.id 和结果；商人先消耗库存，再写关闭日和选择，后续失败保留已付资源。白痴继续用原 setter 替换揭示记录。猎魔人的封印库存和熊的强黎明路径继续经过原专用权限校验。

实际策略、捕获作用域、玩家投影和死亡技能读者使用读取类型，避免标量字段通过旧可写参数类型重新开放。测试中原先用于构造损坏状态的写入只增加具体字段或历史数组的类型断言；原输入、调用顺序、断言和运行程序保持。新单元测试检查安装身份、机械狼 getter 次序、目标读取失败和交易部分失败，并包含有效字段的编译期禁止写入检查。

本批范围为 55 路径：31 个生产文件、23 个既有测试和 1 个新测试。声明、完整运行程序、具体命令体、实际消费者和最终文件摘要分别核对；详细结果见[本批证据](generated/ordinary-role-state-evidence.json)。共享包浏览器类型、源码／测试类型闭合及针对性测试使用实际进程结束结果，不以空日志判定通过。

本批没有改变 schemaVersion 2、独立复现 verifier、自定义 profile 初始化、阶段推进或角色规则。完整状态 schema／编码、剩余私有键消费者、核心不透明状态边界、旧功能门面退出和最终同输入全量验收继续按计划执行。
