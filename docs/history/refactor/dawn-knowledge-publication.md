## 原时点与失败前缀

- 首夜准备成功与猎魔原体检查之后，原 static capture callee → World → nightDay → undefined catalog → config.bear.signalPolicy 顺序保持；默认 catalog 初始化仍归原 capture。捕获之后才调用 NightPipeline／await。
- 只在原 settleNight 尾执行：完整死亡波 await、lifecycle finish／finally、day current 和动物跳票完成事实之后。原特殊夜／Mist 路径不新增熊发布。
- events.length 起点最先读取。frame?.publish 保同 receiver；null 不读取该调用的 World／events 参数或 current 回调，但随后仍读原 Animal 配置。
- Animal true 时即使 frame 缺失／撤权仍调用 note：journal → events.slice(fromIndex) → 按事件 day 去重，随后才发表 Beauty 通知。没有新增“frame 成功”守卫或重复阶段检查。
- 普通 Frame 原 history.push 在事件 push／clock 前；push 失败保已写历史。dawn Frame 原 events descriptor → history descriptor → lease published，失败 checking → revoked 全算法不迁。
- note 失败阻止 Beauty 与后续判胜，并保已公开熊事实；Beauty 失败保已经推进的熊知识。组合不捕获、退款或回滚前项。
- PM 保有原阶段、await／current、animalSkip、checkAndSealResult 的 callee／checkpoint 与唯一封盘；发布接口的运行引用不进入 request／archive，也不是许可或深冻结声明。

## 范围限制

三个公开绑定均沿真实 ports 定位原 class／函数；没有提前执行。当前相对字面声明值图 500 modules／1641 edges，无边回新 owner；这是保守语法图，会计入未显式 type 而实际擦除的 import，外部包、importEquals、非字面入口和完整 cold 执行不计。它不证明其他并行源与基线全字节相同。

新组合输入与公开 Frame 绑定会改变模块初始化路线及 API；不承诺任意 namespace 反射保持。Readonly／方法类型不授死亡或发布权限，新源码、路径及注释按实际生成新 sourceHash；指纹算法、档案字段／格式和历史身份保持，未提供跨构建豁免。
