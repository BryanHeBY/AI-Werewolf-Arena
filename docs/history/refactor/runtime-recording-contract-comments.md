## 就地说明的重点

- 运行依赖属于本局，不进入玩家 DTO；期限回调参与绝对时间的取最小值，重试沿用同一玩家／日期／stage 的预算。
- `stopping` 撤运行入口，`closing` 合并 Agent 关闭调用，`inFlight` 负责等待实际动作；它们不是同一份生命周期状态。
- 动作失败保留已写决策前缀，再取消其它动作；收尾保留停定时器、补事件、关闭、等待、补失败与终档的先后。
- 核心终档失败需要传播，可选调试摘要失败只记日志。失败周期的 checkpoint 保存已经发生的结算前缀。
- 玩家序号只为可见事件递增，不能复用 God 事件索引。God 记录、玩家序号及玩家记录依次提交，异常不回滚已追加部分。
- 主事件游标只在该事件全部处理完成后递增；这不是跨失败重放的原子性或去重保证，注释不虚构此类能力。
- 终档玩家身份使用各规则要求的原名单／发牌与生命来源，属于 God 记录，不能作为玩家策略输入。
