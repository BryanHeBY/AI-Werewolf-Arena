# 原生夜间能力的策略与效果编排

预言家、守卫、女巫、身份查验和狼人五个实际阶段通过三个必填接口接入规则集：拒绝与来源资格、目标解析与提示、已付效果及封印控制器。接口绑定不提前读取 World、日期、目标或库存；没有可选的通用 hooks 袋或统一执行方法。

拒绝策略保留各阶段原有检查顺序和错误码，包括重复的 World 读取、短路与再次梦魇查询。目标解析保持魔术师与时间狼妃各自的位置，女巫的 None／毒药差异仍独立。目标视图保留原引用，隐藏时间回执的 commit 和生命写权；效果接口在原付款位置调用原命令，使用同一个 ctx。

封印控制器的公共 loader 返回原动态 import Promise，不提前加载、不新增 async 包装。公用 helper 及十二个手写测试上下文提供延迟 getter，原输入、操作、回调和断言保持。

本批独立冻结 30 个文件。共享 pipeline 使用明确的 A 候选，生命周期 B 的后续修改独立登记。七个完整原运行程序、九条原拒绝链的 1168 项同输入对照、十二个上下文程序及八个冷入口核对通过。新增局部测试 5 通过、0 失败、17 项断言，四项原阶段代表用例通过；固定 A 源码和十四个测试入口的最终类型检查实际退出 0。详见[证据](generated/native-night-policy-evidence.json)。

本批只收拢这些实际查询和效果决定。完整 RulePlan、狼人迷雾与贵族的业务调度、伤害／死亡扩展及最后全仓验收继续按计划实施。
