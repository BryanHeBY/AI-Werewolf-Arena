# 角色三贡献与领域组件展示退出

本批整合 244 个源码／测试／package 路径：117 个组件所属路径、56 个角色三贡献路径、84 个调用方路径，重叠逐文件登记。[固定证据](generated/role-contributions-and-components-evidence.json)保存完整来源、程序差分、摘要与真实收据。组件工厂调用方与角色新查询同时修改，统一提交避免缺少新所有者的中间构建。

## 实际职责

全部 55 个角色现在显式登记 metadata、runtime、presentation。资料包含身份、名称、简介和有限组合声明；运行贡献包含初始化、规则、阶段、工具、资源相关政策与特权 mock 回调；展示只声明原生 ID 或明确自定义文字回调。原 47 个声明模块及四种共同贡献／继承策略实际分开消费，不创建 flatten 查询门面。

Catalog 的唯一 Map 保留登记原引用；资料与运行有独立查询，真实工具、修复、校验、hook、狼队、查验、组牌和配置消费者全部切换。allRuntime 的角色键来自登记 Map；需要原角色字段的许可消费者仍在 register 首参数位置读 metadata.role，保留自定义 getter 时点。

实际组合根在创建时装配登记表和原生捕获；单独导入角色声明不会提前加载捕获或绕回未完成登记。47 个真实隔离冷导入均成功、覆盖全部 55 项且捕获缓存为空。旧 Git 的 Wolf 单模块冷导入在 Noble spread 有 TDZ，旧失败保留证据；本次按目标消除该装配环，不宣称所有冷加载失败机械等价。

Alive、Camp、Badge、VotingRight、StatusMarks 的领域组件退出渲染；游戏观察层保存语言绑定并在原读取点生成纯片段，共享展示包立即格式化。保留 Badge／Vote 短路、StatusMarks 原生 size 及 values.call receiver／逐项 map 顺序、locale 仅 undefined 时采用默认值。Demon 库存信任仍按五个真实方法顺序检查，并在原最后位置拒绝注入退休的渲染名称。

## 明确的 API 迁移

内建 PROFILE 的旧 flat shape、profile.renderPrompt 转发、get／require／all 和类构造的隐式默认装配退出。调用方使用 createRoleCatalog 和三个贡献的实际 owner。自定义 flat profile 仍是受支持的用户原文输入，保留原对象、init receiver、显示方法两次 getter 和晚 World 求值；不会探测新 metadata descriptor。

五个领域 renderPrompt 方法及 StatusMarks 的可枚举 locale／重绑定入口退休。代码不再赋予数据组件文字职责；非法旧 call／rebind 操作不作为新 API 兼容承诺。静态内建声明的字段分组会改变对象属性形成顺序，完整逆证明验证原值和全部回调算法，不能据此宣称任意 getter 声明的求值顺序完全一致。稳定角色 ID、工具参数、规则和归档字段不随本批改变。
