# P4 G02：女巫刀口、资源及保护结算

规范以唯一[基础规则卡](../rules/awa-classic-v1.md#witch)为准。本页记录女巫实现边界、保护组合与验收，不复制其他角色规则。原生和赠予用药能力共用[夜间能力实例](night-abilities.md)契约。

## 输入与资源

- 解药只救当夜仍存活且有有效 WolfKillMark 的实际目标；不存在、已死、历史刀口或伪造目标拒绝。自救按当前实际 day 与本板禁用／首夜／始终策略校验。
- 同夜至多一药，明确 none 不耗药。schema/业务预检不消费；最终执行再验目标、角色／实例、有效窗口和资源，合法动作才一次消费。非法目标可在同一未截止窗口更正。
- 解药耗尽后本夜请求不携带 wolf_target，共同提示显示未知；不会把 null／未知当作已知平安夜，也不删除本人历史用药事实。用药不额外授予狼队视角；已有独立合法权限和历史知识仍保留，不能为耗尽限制撤销其它角色权限。
- 毒药独立选择存活目标，可自毒；毒药可用不意味着可以读取刀口。原生与赠予能力仅暴露本人获授权的实例状态。

## 保护及独立死因

守护和解药只阻挡狼刀，不消除毒。在本板默认同守同救冲突下，GuardMark + HealMark + WolfKillMark 仍留下狼刀死因；是否有毒都独立处理。没有狼刀的同守同救不会自行制造死亡。

DamageResolutionSystem 返回 deaths 与明确 DeathCause，并清除夜间标记；它不写 Alive、不处理遗言／警徽／枪或判胜。[死亡结算器](death-chain.md)拥有这些后续动作。复合死因含 Poison 的猎人不能开枪，不能靠末神判断掩盖禁枪规则。
