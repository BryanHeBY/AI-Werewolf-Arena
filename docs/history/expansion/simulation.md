# P2 T03 受限观察模拟

## 权限边界

`PlayerPromptPolicy.buildObservation()`生成与提示相同来源的本人身份、自己的角色状态、授权队友、允许工具和已有玩家可见事件。已知存活名单仅从公开死亡事件推导，不查询未公布的死亡真状态。DTO深拷贝并冻结，策略不能改写领域组件。

`ObservedPlayersActionProvider`是持有world的适配器。`ObservedBot`只接收DTO及该玩家命名随机流，不持有world、全部底牌、敌方身份或上帝记录。控制器可以读取真状态来验证资源/死亡和落盘，但不将其交给策略决策。对方隐藏身份/状态变化不改变平民观察及决定的测试已建立。

决策端得到的是真实包装后的`next()`能力，不能访问root seed、路径或fork其他流；不是仅用类型隐藏完整随机源。实际seed及随机元数据只保留在控制器和内部记录中。

基础狼队互认是已经获得的身份知识，秘密死亡不会把已知队友从名单移除；是否存活仍依据公开事件。该修正同时用于LLM/ACP共享系统提示。另有狼队未公布死亡不干扰观察/行动测试；P4扩展特殊狼互认与事件发生时授权。

## 策略与随机流

- `active`：积极用药/守护、后续日自爆概率分支。
- `conservative`：保留药、空守，其他必须动作照常完成。
- `competitive`：主动争警徽、使用已知查杀归票。
- `random`：随机合法目标及方向。

所有策略对普通目标只使用公开存活事实；狼刀避开授权队友、预言家使用本人查验历史、女巫使用本次授权刀口。策略不读取真实敌方阵营。

玩家决策持有`players → id:<id>`流；风格选择使用`styles → id:<id>`流。相同seed的风格和决定不依赖它在批次中的位置。批次/记录目录用独立UUID，不参与领域随机，也不覆盖先前模拟记录。

## 可用命令

从项目根目录：

```bash
bun run --cwd backend simulate --configs-dir ../configs.example --board six_player_mvp --count 25 --seed-prefix regression
bun run --cwd backend simulate --configs-dir ../configs.example --board twelve_player_standard --count 25 --seed-prefix regression
```

此入口仅读取板子，不加载providers/agents或宿主认证，不调用外部模型。count为1–1000；默认在项目根`record/`下新建唯一批次路径，保持与游戏运行相同的路径规则。可选`--record-root`指定记录根，相对路径按CLI当前cwd解析（`--cwd backend`时为backend目录）。

报告给出每局实际seed/结果/记录目录、自然结束数、拒绝/回退数及已生效分支统计；用药区分救/毒/跳过，守卫区分保护/空守。达到天数上限单列为非自然终局，存在拒绝、回退或非自然终局时CLI退出失败，不用角色出现次数冒充技能分支覆盖。

## 已验证范围

六人/十二人各25固定seed全部自然结束，0拒绝/回退。六人有守护与空守；十二人有救药/毒药/跳过、猎人开枪、末狼自爆、白痴翻牌及警长选举。每局公开档使用共享契约校验，结果和报告一致；取批次中第5局单独重跑结果/分支保持一致。

策略边界另测：隐藏敌方底牌/私有资源/未公布死亡不改变观察及决定；本人私有状态可用且不能修改world；狼人仅取得授权队友。人工关键规则正确性由T02完整脚本验证，随机分支覆盖作为补充。

当前覆盖基础两板子；没有把任意角色组合宣称已验证。控制器检查自然终局、死后动作授权、不可复活及药资源不负数/不增长；更多来源、伤害与能力不变量随P4扩展。T04继续建立严格失败录制及离线回放，现阶段模拟目录不等同于完整可复现录制。
