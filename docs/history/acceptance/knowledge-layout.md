## 保留的失败与修复因果

历史迁移首次预检发现两个未被 Git 捕获的忽略日志；未改任何历史原文件。跨文件系统 `rename` 随后失败，另一轮预检仍拒绝相同残留；最终复制并逐字核对两日志、保存 manifest 后移出旧根，后继迁移成功。两日志共 37,322 字节，另存封包，不计入原 5,511 项。

fixture 首轮两项失败分别来自：负例临时目录没有复制当前真实读取必需的支持文件；派生清单仍缓存共用源码的旧摘要与大小。修复保持负例断言、canary、清理和既有有效性规则，精确更新清单标量。Root 的修复应用脚本首次在写入前因记录字段判断错误退出，修正后才实际应用；原输出和脚本前样均保留。
