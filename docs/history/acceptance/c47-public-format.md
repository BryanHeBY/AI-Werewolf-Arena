# C47 公开源码格式与原始夹具归属

基于 `ef993352`，本笔统一维护源码格式、收窄原始回放的格式选择政策，并继承真实 current 字节缓存。规则与原始身份不变。

## 实际范围与验证

- 2271 个公开维护输入分 18 批格式化，257 个主／派生清单分 3 批格式化，全部退出 0。
- 全部 904 原始回放、5511 冻结历史及不透明档案保原字节与模式。Prettier 实际核对 6677 项忽略政策，无失配；六条规则不忽略维护清单或源码。
- 770 个格式变更文件逐程序／JSON 比较：768 份源码、2 份 JSON。首轮 12 个解析上下文标记差异单独定位，仅重查这些失败文件后通过。共保存 1536 对双模块输出，其中 678 对原文相同、858 对原文不同而完整结构相同。
- 只在本次已定位差分的证明表示里归一化 `AwaitContext` 位，实际 await 语法、可选链及其它标记仍比较；不把该许可推广为任意代码的语义等价。
- 五份原程序／绑定合同、原迁移声明和包端点通过；仅迷雾乌鸦辅助源的实际 current 摘要／长度变化，派生清单从原 API 继承。原 program、binding、origin、suite 与 acceptance 均未重写。
- 正式夹具检查通过：907 档案、904 原 JSON、5 源程序证明、258 组、256 派生清单。
