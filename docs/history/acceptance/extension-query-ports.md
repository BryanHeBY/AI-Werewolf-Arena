# 可见性与判胜扩展的窄查询

实际前态为 `f041aaf4`。两类可替换查询扩展退出原 `World` 参数，真实回调对象只提供标量、编号数组与具体判胜数据；没有组件、通用实体写方法或取得世界的回门。

可见性继续先处理家族和历史受众，自定义回调仍在原位置裸调用并接收原事件副本。判胜继续先过滤检查点，再以原规格作 receiver 调用评估；存活统计、丘比特、婚约和胜利成员构造均由原资源所有者计算。绑定本身不读组件，默认注册表不缓存局内世界。
