# 私有选择事实的实时录制接线

基于 `da664f6d`。丘比特／混血儿发布的私有事实会在下一周期快照前进入后续请求，而这两类板子的录制入口没有接通既有实时事件读取回调。定时写盘仍使用旧快照事件，严格校验因此拒绝真实对局。实际拒绝输入已捕获；丘比特九份记录是同一场景的多次写盘尝试。

生产只补这两类非零角色牌组的回调选择，保持 God 全事件流及脱离副本；不推进 checkpoint，不放宽验证器，不改变行动付款或玩家可见内容。新增测试通过真实入口、角色阶段与请求工厂，在没有后续 checkpoint 时核对事实、隐私和篡改拒绝；关键所有权与时间边界均有中文说明。

## 实际验证

- 两类确定性回归均先在旧接线上得到对应严格校验错误；修补后分别通过 11 与 9 断言。
- 混血儿原失败的 21 条完整双语场景通过，10,015 断言。
- 丘比特文件原失败的 21 条场景通过，4,637 断言。该组含 15 条仅快照错误、2 条仅死亡来源错误、4 条双根错误，后两类还依赖前笔死亡来源修复。
- 最终两个修改根及真实传递图类型检查通过。首次测试构造字段放错层级的 schema 失败保留，后继按真实工厂边界修正，没有削弱断言。
- 独立审查通过；原 Trace 和两类严格验证器保持原字节，原普通板子回调策略保留。
