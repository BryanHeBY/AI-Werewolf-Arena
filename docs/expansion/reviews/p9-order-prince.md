# P9c 定序王子有限板功能验收

日期：2026-10-11（UTC+08）。基线 main@f0d3d65。仅登记本规则的 implemented，不关闭 P9c/P10，不代表所有同名玩法均受支持。

## 支持范围

公开预设 awa_order_prince_12_v1：四普通狼、四村民、预言家、女巫、猎人、定序王子，十二人原生固定身份、屠边、既有警长与一轮 PK。
政策 awa_order_prince_first_ballot_v1。每天原始首轮放逐投票结束、任何死亡与遗言前，仍存活且未消耗技能的王子必须明确发动或不发动。可救自己或他人；首轮平票与全弃票开放是本规则明确解释。PK 与重投不能递归发动。
发动先提交一次性消耗和公开翻牌，再额外发言与重新收票。技能发言不开放自爆；保留警徽与票权。原票不造成死亡，重投重新核验存活选民、目标和票重。失败保留已提交前缀，不恢复库存或伪造完整轮次。

这是独立 AWA 有限板，不声称已实现网易永序之轮整板；魔术师/诡术师组合留待下一批冻结与验证。

## 修复与独立审查

修复生产 stage.* 缺键、原始事件 fallback 阶段译名缺失、合法发言清洗与 Tape 对比不一致、recording 跨层导入、票据与决策绑定、独立警徽票权核验、完成轮次遗漏弃权票据和 PK 发言未绑定决策。
PK 发言审计严格限定 Voting 阶段，避免误判次日普通发言；部分失败前缀只有到实际收票/汇总边界才要求前置发言全部完成。删除票据、改写或删除 PK 发言均有拒绝回归。
独立只读审查确认票据覆盖和 PK 发言两项缺口已在源码闭合；执行门禁另据实际日志。
测试编写中两处类型收窄错误均保留失败日志；Chromium 初次启动因硬盘临时目录 socket 路径过长，改短目录后四项通过，无需使用容量紧张的 /tmp。
