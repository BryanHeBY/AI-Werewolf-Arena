## 三路问题与复查

- **A（架构/测试）**：发现 ACP report_bug 没有检查 owner deadline，导致过期报告仍有回调副作用。已统一两通路的 authorize，并补过期/错误会话/stale/已封口报告与合法报告后正常行动。最终复查确认同步一次选择、失败保持开放、选中结果复制、SDK 不信任伪造 finalAction、预检不双记领域日志。后加 SDK toolSpecRegistry 传递与候选校验也复核，0 剩余阻断。
- **R（规则/权限）**：发现警长非弃票在缺少候选 context 或候选已死亡时仍可能接受。已要求存在候选列表、目标属于列表且仍存活；缺列表/死亡10/非候选3拒绝后同 t1 合法2接受。药枪资源、角色/存活/目标、死后动作来自引擎请求、bool 类型与封口验证通过。旧 heal 任意目标等差异明确留 G02/G03，0 剩余阻断。
- **L（语言/数据/兼容）**：发现接受说明容易被理解为保证最终生效，已改中英文工具描述与静态 schema 为“已选择、尚未生效、再次校验、结果事件为准”。两语 stale report_bug 的重试工具名与完整回执一致，无其他玩家私有数据；协议补充字段与 World 构造要求已说明，0 剩余阻断。
