# 规则证据与具名策略边界

核验日期：2026-10-09。AWA默认基线是 `eb4f026` 的 `awa_classic/1.0.0`，不是某平台全部规则的镜像。采用官方页面或官方账号发文为主要证据；区分年代、板型和赛事。`langrensha.net` 是独立站，不能标成网易官方。下表不把比赛扣分、攻略推断或旧版行为自动提升为引擎强制规则。

## 本批完成的规则配置

公开板子 `roles` 中只有实际在场、已实现角色的参数可通过严格schema。未知key/值、无对应角色、角色组合不支持仍报错。可在既有守卫/隐狼板子分别填入：

```json
{
  "roles": {
    "guard": { "repeatPolicy": "netease_consecutive_nights_v1" },
    "hidden_wolf": { "campInspection": "netease_2020_good_v1" }
  }
}
```

这是角色参数片段，完整板子还需合法人数/角色组合及其余v2字段；不能把片段当作完整配置。省略时分别归一化为 `awa_last_action_v1` / `awa_inheritance_v1`。不覆盖本地configs。
