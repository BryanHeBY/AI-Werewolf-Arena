# 事件、回放与版本契约

领域事件事实、玩家可见事件和展示DTO分别表达。旧公开回放仍可读，reproduction/Tape保持严格引擎/源码/锁文件/规则版本兼容，不能用旧source fingerprint冒充新源码。

## 统一读取与关联

回放处理在使用payload前经过共同事件reader；畸形事件不得造成存活、投票、胜利、玩家关联或展示副作用。未知历史事件保留可解释的中性表现，不根据未校验字段猜角色事实。reader和玩家关联提取共用语义，不让时间线/投影/舞台各自维护字段猜测表。

公开回放是God视角，可展示全知底牌；这不赋予对局Agent公开身份知识。展示类型不扩散到领域或机器契约；展示文本、颜色、标签不成为权限依据。

## 名称与历史

黑市受赠能力采用能同时容纳奇迹/黑市来源的中性展示标签，保留既有历史事件名及legacy读法；不得为了UI改名重写已记录事实。补齐审查指出的14个行动阶段映射，并以完整稳定stage集合断言覆盖；不能仅增加部分手写测试值。

## 参数及版本

归一化板子、现有角色规则参数和ruleset进入reproduction；公开reader兼容与内部严格Tape是不同通路。新增格式字段明确缺省/legacy行为，规则语义未改不得伪造新玩法版本。

证据：`packages/replay-contract/src/index.ts`、`backend/src/recording/reproduction.ts`、`runtime/simulation/reproduction_context.ts`、`frontend/src/replay/`。实施前复核每项事件消费者及当前损坏文件拒绝边界，避免重复校验或扩大公共包对展示的依赖。

回归至少覆盖畸形payload无副作用、未知/旧事件、玩家关联完备、黑市/奇迹受赠历史、中英阶段完整映射、往返参数、旧公开回放与当前录制。必要的浏览器/视频构建只使用离线fixture，不启动真实对局或模型。
