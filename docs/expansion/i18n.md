# P3 中英文本契约

## I01 共用目录

`packages/game-catalog`继续拥有64角色稳定ID、中英名称和实现状态。`packages/game-text`拥有规则/阶段/原因术语、完整句子模板及格式化；两者不依赖后端引擎。后端角色查询和前端角色标签引用同一资料。

- Locale仅`zh-CN`和`en`，缺省中文；每个调用显式传值，不修改全局“当前语言”。
- 中文/英文key集合与占位参数集合必须完全一致；内置缺key、参数缺失/多余/非法值明确失败，不用语言回退掩盖。
- 角色名只从game-catalog查询，不建立另一份七角色或64角色词典。
- 内置技能说明的中英文查询都从共享模板取得。旧profile的label/skillBrief字符串暂作API兼容声明，I02继续清理；构造器显式定制文本视为调用方原文，在两种语言都保留，不借用同ID内置译文替换。
- 未知历史角色/阶段可原样显示稳定ID，主动游戏配置仍严格校验。
- 玩家昵称、人格、发言、遗言、自爆理由和模型原文不翻译；参数按原值嵌入模板。
- 根词典冻结，交错中英文调用不产生共享可变语言状态。

I01先交付目录和契约，英文对局入口仍需I02–I04全部接通、审查和验证后开放。基础七角色的英文技能说明描述当前实现，包括尚待P4修复的末神禁枪；不能在翻译阶段悄悄修改规则。

## 接续实现边界

1. I02逐局locale传递到规则/目标/提示、实际SDK游戏工具及参数、游戏/审计MCP sidecar、拒绝、终端和审计摘要。审计关闭的fallback也得到展示语言；字符串启发式成对覆盖中英文，证据ID不翻译。
2. I03新记录统一phase/stage/原因机器ID，展示消息使用key/params；公开版本/新writer/旧reader/精确转换同时提交。旧中文仅已知别名转换，未知保留，用户原文不改。
3. I04前端与Remotion locale/时区为显式输入，工作台语言不修改replay；同frame同输入输出稳定，中英E2E验证。

T04内部动作录制与公开复盘分别有版本政策：旧动作录制可以按严格engine/hash拒绝；历史公开播放器档必须由显式reader/转换继续读取。不能把二者混为同一个兼容承诺。
