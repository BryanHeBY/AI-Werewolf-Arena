# AWA 白昼学者与寂夜导师有限十二人板

状态：implemented，有限板已通过[完整技术门禁与独立交叉审查](../reviews/p9-scholar-mentor.md)。目标板：3 普通狼、寂夜导师、4 村民、预言家、女巫、守卫、白昼学者。禁止复制、转移、换位、第三方和复活组合。

## 官方事实

- [2022-03-03 公告](https://langrensha.com/news/official/20220303/26904_1005183.html)及[学者角色卡](https://nie.res.netease.com/r/pic/20220303/2a40c8f8-574c-4e9e-a399-fe13d0b631c2.png)、[导师角色卡](https://nie.res.netease.com/r/pic/20220303/470ff13c-8909-4a94-ba3e-c5ca968b968a.png)：第二夜开始，每个施法者全局各一次增强、一次削弱，每夜至多选一个；导师继承技能使用和效果。不是每夜刷新两份资源。
- 导师无其他狼身份信息、不参加狼聊或狼刀、不能自爆；普通狼知道导师；导师成为唯一存活狼时可袭击。
- [2022-03-07 冲突说明](https://langrensha.com/news/official/20220307/26904_1005571.html)：同时作用同一好人则该好人死亡，双技能无效；同时作用狼人，目标相同或不同，导师死亡，双技能无效。
- [2022-03-23 官方教学](https://langrensha.com/news/official/20220323/26904_1008702.html)：增强查验、守护、毒药、狼刀可有额外行动；额外查验、守护、狼刀不可选同一目标。削弱狼阻断狼队袭击。普通村民无效果；双方能力相互无效；因冲突死亡的神仍执行本夜原生技能。

核验日期：2026-10-11（UTC+08）。以下未由官方短文消除的边界，作为明确 AWA 政策，不宣称统一官方解释。

## AWA 明确政策

policy = awa_scholar_mentor_twelve_v1。

- 存活目标可含自己；两个施法角色均对修改效果免疫，先过滤免疫再计算碰撞。合法选择对免疫者、村民或发生碰撞，仍消费所选一次资源；明确空过不消费。缺失、非法、超时不能自动空过。
- 基础行动与额外行动分别记账，额外行动只活到当夜结束，不修改永久原生库存或最大次数。额外行动可明确放弃。
- 女巫削弱只阻止毒药，解药保留；增强给予当夜独立额外毒药，即使原毒已用尽仍可用，不补回原毒，不提供额外解药。额外与基础毒药目标不同。
- 守卫基础守护遵守上一基础守护的连续限制；额外守护不检查或改写基础历史，但必须不同于本夜基础守护目标。
- 额外行动使用独立的一次性当夜授权及独立请求，不通过重置原生 lastUsedDay 或永久能力库存获得第二次机会。
- 女巫尚有解药时可见本夜全部有效狼刀目标，仍只能用一瓶解药救一个目标；额外刀不提供额外解药。
- 基础与额外查验、刀口也必须不同。增强普通狼的额外刀由该被增强狼独立选择；基础狼队票决不重复全队投票。削弱任一普通狼阻断本夜整个狼队的刀。
- 导师刀权以夜初是否仅剩自身为准，夜间结算中变成唯一狼则下一夜接刀。成为唯一狼后仍可使用剩余修改技能；仍禁止自爆。
- 两份选择先提交，再统一计算冲突和效果；冲突致死记入待结算死亡，不在原生技能前摘除玩家。取消两份修改但保留被冲突神的基础行动；白昼才公布死亡，不提前向玩家暴露对方施法者或选择。
- 严格固定原生十二人板。复杂组合、任意注入能力和全量角色混用不在支持范围。
