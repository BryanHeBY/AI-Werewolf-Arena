# AWA 动物梦境原生十二人规则卡

版本 `1.0.0`，联合规则 `awa_animal_dream_v1`。本卡为经三路预审的实施目标；白猫、子狐、河豚仍为 planned，实际对局与交付门禁完成后再登记 implemented。

## 来源与裁定归属

网易[2021-10-21 上线说明](https://langrensha.com/m/news/official/20211021/26904_980676.html?mbshare=cplink&spreadtimes=21)及[2021-10-25 玩法说明](https://langrensha.com/news/official/20211025/26904_981415.html)提供角色构成与基本技能：子狐次夜起单次迷惑，命中狼阵营取消整队当夜狼刀，命中狼美人另取消魅惑；河豚放逐票后可反击投给自己的玩家，刀死时封锁当日狼美人技能；白猫致死后亮牌并延迟至下次放逐投票后；熊按天亮存活邻居发匿名信号。

玩法文章明确河豚同时带走全部羊驼与狼时仍判狼胜。本卡将同时达成双方屠边条件的完整死亡链统一采用 wolf priority，此推广属于 AWA 裁定。静态角色目录河豚说明含与两正文相反的“没有选中”字样，本卡采用一致的两篇正文，不引入未被狼刀选中就自动死亡的行为。

下文的首次延寿一次、空过、自选、PK、跳票到期、公开时点、严格失败、库存及记录边界均是明确的 AWA 补全。它们不代表所有平台同名角色的完整细则。

## 牌池与固定支持

仅支持此精确原生十二人组合，固定 SlaughterSide 与 `awa_wolf_priority_v1`。最终全体获胜阵营成员列入 winningPlayerIds，含已死成员；整条死亡链完成后由 PhaseManager 发布唯一 game_over。

警长：`awa_nomination_offstage_pk_v1`、一轮 PK、权重 1.5、`awa_holder_choice_v1`。放逐：`awa_one_pk_v1`，平票无放逐。普通狼刀票平票取最小 ID；警长票平票无人当选。死亡默认 hidden；白猫首次延期、河豚发动或实际刀死的公开亮牌是本卡明确例外。遗言采用 `awa_initial_wave_v1`。普通狼仅 preElection、preVote 两窗口可自爆；狼美人保持现有禁自爆、自刀及 `awa_exile_poison_v1`，本板实际只有放逐触发其牵连。

无额外身份、赠予、复制、复活、第三方或其它扩展机制。羊驼使用既有 villager 稳定 ID，无新的平民角色条目。

## 子狐

N1 无技能请求。N2 起，原子狐活着且单次资源可用时，每个真实夜晚一个 `fox_distract {target_id:number|null}` 机会。可选自己或任意当前原活人；null 明确空过、不耗次数。任何非 null 合法选择都消费整局一次，无论目标阵营。

命中任何狼阵营原玩家，整个狼队本夜无普通刀请求或许可，狼聊、互认保持。命中狼美人还在同一提交点清当前魅惑及真实绑定，保留旧历史、另记 blockedNight，不伪造美人 null 行动；该无行动夜打断连续目标限制。分支 A：N1 美人选 5，N2 子狐封美人，D2 放逧美人不带 5。分支 B：D2 放逐其它人保留美人，N3 可再次选 5。

本人只获自己的选择与剩余次数，不获命中、真实阵营或禁刀结果。狼队每人仅获自己的当夜刀许可；美人仅获自己的魅惑不可用，不获子狐 ID。已付效果持续本夜，原施法者首次真实死亡不倒销；下一真实开夜到期，阶段标签本身不构成开夜。

## 白猫

整局首次致死提案在真实提交边界消费延寿，公开亮牌且保留真实 Alive 引用、值与版本；不先死再复活。God 保留首次原因和延期时钟，玩家只获已公告的亮牌／仍存活事实。延期期间再次致死不提前死亡、不刷新期限。投票、上警、警徽与熊活邻位仍按真实活人处理；翻牌不授遗言、不移徽。

一次放逐单位包含首轮及至多一轮 PK，最终平票、全弃票也完成单位。夜间或早于该单位首次延期，可在当日之后的单位到期；因该单位放逐／反击／追加牵连首次延期，等下一单位。默认自爆跳票不造成到期；另一政策在该白天真实中断单位到期，含本次合并夜死刚翻牌的猫。

到期使用新 `WhiteCatExpiry` 来源，首次被挡死因仅留历史；与本单位新 Exile／Puffer 真实来源合并，真死、Alive/version、遗言／警徽只处理一次。自爆／合并夜死 → CatExpiry → 每波遗言／警徽／追加链 → 判胜；末普通狼自爆且最后神为 pending 猫时，等待实际票政策 Good 胜，跳票到期政策 Wolf 胜。

## 河豚

最终放逐票轮完成后，仍为原活人且主动资源可用的河豚先获得反击决定，含本轮拟放逐的河豚。目标全集来自所选首轮／最终轮实际接受的原投票；不从总票数、模型目标列表、错误／弃票或警长选票推导。1.5 权重仍是一个选民。普通放逐沿既有合法自票；PK 候选无投票权。

仅一个 `puffer_retaliate {activate:boolean}`，引擎决定目标全集。false 空过零消耗；无当前合法原选民则无请求、零消耗，伪造 true 拒绝。true 经最后授权同步付款后消费整局一次，公开发动亮牌并提案带走全部目标；不能自行选子集。首轮 A/B 投河豚、PK 全弃时，first 为 A/B，final 为 [] 且无请求，不回退首轮。

主动资源与刀死被动独立：主动已使用但后来真实原刀源死亡，仍在黎明公开河豚身份并封锁当日 Beauty link；被子狐取消的刀不触发。封锁在下一真实开夜清除。夜死河豚不再获得反击请求；主动反击和刀死均不提前封盘，完整真死亡链后判胜。

## 顺序、公告与信息

真实开夜到期 → 子狐 N2 选择150 → 狼聊200 → 普通刀400（未封锁）→ 美人450（未封锁）→ 原夜伤害 → 白猫延期过滤／实际完整死亡链 → 实际刀死河豚封当日美人 → 每波遗言／警徽／角色钩子及追加波 → 熊天亮取样公告 → PM 判胜。

N1 警长选举在真正夜结算／公告之前；期间本人和其它玩家均无待提交 Cat pending／Puffer 刀死信息。正常黎明、后续黎明及 preElection 合并自爆均在真正结算点发布。熊原 owner 夜初锁定，天亮策略只延后读取原体当前活邻位；原熊真死则 quiet，替换／复活不获取旧帧授权。

夜公告取冻结原夜伤害集合与实际提交集合的交集；纯自爆与当前 CatExpiry 不列昨夜死，原刀与自爆重叠可列一次，空集合也公告一次平安夜。Animal 的 voted_out 仅在真正 Exile 死亡提交后发布；Cat 延期只亮牌。God 提案／blocked／committed 事实始终无前端 Alive effect，存活由实际公共死亡事实改变。

白天：最终票 → 河豚决定 → 普通 Exile／反击／本单位到期实际波 → 美人追加提案与白猫过滤 → 每波词、徽、钩子及后续波 → 唯一判胜。每个波先该波全部遗言、再全部徽；追加波仍按相同顺序。

## 授权、取消与失败

请求绑定原 World／阶段租约、Role／独立 Camp／Alive 版本、私库／能力、库存、目标或原票集合及最早截止时间；await 后、最后外部回调后复验，随后同步提交唯一资源 receipt。MCP accepted=true/applied=false 是预接收，不是付款；撤权、域拒绝、超时均不耗。

Fox 及有合法对象的 Puffer 是必需决定，null／false 与 missing／invalid／late 区分。后者中止并保存失败前缀，不用兜底代选。已付款后 transport／required-op 失败保 canonical 已提交库存与历史；未提交生命不编造死亡，关闭不造正常 dawn／expiry／亮牌事件。Cat 已延期或实际到期后录制失败同样保原真状态及已发布知情，撤权对象不能通过 getter 回填 CP。
