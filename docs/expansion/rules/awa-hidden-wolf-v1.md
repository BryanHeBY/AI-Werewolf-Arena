# AWA Hidden Wolf 1.0.0 规则卡

awa_classic 1.0.0角色扩展，ID `hidden_wolf`，隐狼／Hidden Wolf；核验2026-10-08。本版选择熊隐狼的普通潜伏／接刀版本，与“迷雾生还者”的互不相认、固定带刀顺位、永久角色伪装分别处理；觉醒隐狼仍P7另一项。

## hidden_wolf

- 狼阵营及Wolf胜利归属，计入狼人数／屠边／屠城，原生count最多1。正常公共发言、投票、警长和放逐；不能原生自爆，没有原生死亡枪／毒／魅惑。
- 单向知道其它当前Wolf阵营玩家的授权ID，不揭特殊牌型；普通狼队不知道隐狼ID。隐狼不参加或读取普通狼夜聊，无论是否接刀；不补发过去未获授权的狼聊／刀票历史。认识身份与当前存活分别表达，不能用队友列表暗报尚未公布的死亡。
- 开局若本身是唯一活狼，立即获得基础刀权；否则在真正死亡提交后，存活隐狼成为唯一活Wolf时接刀。不是按“投票已定／药已用／预计死亡”提前接刀。同批其它狼和隐狼一同死亡时，不曾存活成为末狼则不接刀；追加波先死其它狼、后死隐狼时保已获得事实。
- 已获得事实在本人原state中持久保存，actor-only `hidden_wolf_awakened {actorId,day}`只发一次，无他狼列表／数量／死因。当前刀行动还必须本人原生命存活、Role/Camp/state有效且当前只有该Wolf；复活其它Wolf或改变组成不能让旧资格绕过唯一活狼条件。失去当前刀权不会伪造撤销“曾获得”事实。
- 刀权只在Night的普通`kill_vote`流程实际行动，可弃票／基础自刀，沿原狼刀计票／保护／伤害规则。白天获得刀权不立即加一次行动，下一夜正常收集；没有夜聊或原生主动查验请求。非法／迟到／撤权不提交票或造成伤害。
- 未曾获得刀权，阵营查验显示Good、不触发熊；接刀事实生效后阵营查验显示Wolf、可触发熊。熊仍按其入夜样本，不在当夜末狼死亡后回算。Knight根据真实Camp.Wolf决斗，不能用查验伪装躲决斗。
- 本AWA版本的具体角色查验在未接刀时显示Villager、接刀后显示Hidden Wolf；这是明确补充细则，不采用迷雾版“接刀后永久平民”。死后查验／守墓反馈保曾获得事实，不因为Alive=false重置伪装；未接刀被直接放逐则守墓报Good，但真实狼仍被消灭并按真实Wolf胜利归属判胜。
- 本人prompt/DTO只含授权身份ID、本人接刀事实及当前可行动资格，无全局隐藏狼数量／候选／他人state。接刀消息不是公共身份翻牌；终端关系诊断沿private flag，独立IO／思考为operator通路。公共死者／普通刀口不额外揭隐狼身份。

## 所有权、参数与支持边界

角色持有原native state `{hasInheritedKnife:boolean}`；bootstrap／实际死亡提交点同步更新接刀事实，查询、预检、prompt与熊感知不修改state。DeathResolution仍唯一写死亡，PhaseManager最后judge；同一死亡波中先提交真实死亡、再同步接刀事实，再遗言／警徽／技能，保已提交前缀。

动态当前权限按World只读查询，缺World的旧低层权限调用不给隐狼刀权，普通狼旧调用兼容。刀／聊行动await后校验原actor／生命版本／role/state引用及当前资格，阶段取消不能晚记票／落刀；其它角色正常已提交动作不被回滚。

有效票历史保留，但每张票绑定原目标生命，计票不把旧生命票转给同ID的新生命。选中狼刀范围只在Night内部保存生命／标记引用，在后续阶段与Damage前复验；首日延后夜死到竞选后时，实际死亡前也复验NightDamage原生命。复活／组件替换使旧伤害失效，实际NightResolved名单不含新生命；不撤其它毒／守护或合法新生命票，临时引用不落盘。

`roles.hidden_wolf`仅{}，不开放夜聊、永久平民、额外复制或固定刀顺位等未冻结参数。公开6/12使用当前已注册角色的AWA组合；来源白神不冒充白痴。与熊／seer／gravekeeper／Knight和狼枪／白狼／狼美人的核心交互需人工判例；石像鬼、通灵师、觉醒隐狼及迷雾板的其它版本在对应批次另冻／另验，不凭同名自动授予许可。

## 来源与AWA细则

[熊隐狼标准板](https://melbournemasters.org/setups/xiong-yin-lang)明确单向知道狼人、唯一活狼接基础刀、未接刀不查为狼，以及无刀隐狼不触发熊。[角色页](https://melbournemasters.org/setups/roles/隐狼)同时列迷雾版第三刀位／永久具体角色平民／互不认识，页内已说明按具体版型核验，本版只采用前一规则。

不夜聊／不原生自爆、单原生隐狼、实际死亡点与同批／追加波时点、原state永久“曾获得”与当前唯一活狼资格分离、角色查验标签、死后反馈、历史授权／复活／取消生命边界为AWA明确细则，均需独立判例；不宣称各平台相同。

## 必验矩阵

开局唯一狼／最后其它狼Night或Day死后接刀／同批同死不假接刀／追加枪链接后死亡；单向ID而无特殊牌、无夜聊／旧历史／票权预借／自爆；只读预检与当前刀资格/原生命role-state撤销、Night死亡尚未公布前不预接刀；伪装／接后／死后阵营与具体角色查验、墓反馈、熊采样与Knight真camp；接刀夜正常伤害/保护/弃票/自刀、终局后不请求、真实Wolf人数及dead获胜者；中英工具/状态/错误/终端/记录/前端/实际frame；公开6/12 strict参数与count；SDK/ACP/混合×两语字面完整局和逐局Tape、两板各20受限seed实际潜伏/接刀/刀票正覆盖及全部重放，三路交叉审查与功能提交门槛。
