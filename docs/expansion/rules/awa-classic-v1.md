# AWA Classic 1.0.0 基础规则卡

规则集标识 `awa_classic`，规则版本 `1.0.0`。这些规则是已选择的规范；资料登记与运行 profile 分开，只有实际注册的角色才能开始对局。基础七角色已有实现，但下文差异关闭前不登记 `verified`。

## 通用规则

- 稳定玩家 ID 与座位独立；正常开局随机发牌。暗牌局只有规则明确要求的身份公开。
- 生存玩家在规定窗口行动；死亡动作和遗言需要明确授权。
- 狼刀、毒、枪、放逐为不同来源。守护及解药只抵挡规则规定的伤害，不消除毒死因。
- 多个胜负条件按板子声明的顺序检查；屠城、屠边、人数优势是不同条件。现有示例的组合为 AWA 明确改编，不宣称是单一官方屠边。
- 当前兼容首日流程：夜间技能与待死亡名单先结算，警长竞选后公布首夜死亡；待死亡玩家按该流程参与竞选。
- 当前自动警徽转移与离散自爆窗口属于 AWA 改编；新版本改变此行为时单独声明。
- 默认遗言：首夜初批死亡、放逐死亡有遗言；基础版追加死亡和普通自爆不提供遗言。其他变体另行登记，不能从死因名字猜测。

## wolf

狼人 / Werewolf：普通狼双向互认，按公开给本人的狼队范围夜聊。最多三轮夜聊，与狼刀票使用同一随机顺序。可弃刀、自刀或刀队友；平票按本板参数处理。默认自爆窗口为放逐前，空列表明确关闭；扩展窗口只有实现后才可配置。多个同时提交以最小稳定玩家ID选一人，普通自爆中断白天并入夜，警徽必须进入死亡处理，不能留下死亡警长。

## villager

平民 / Villager：无夜间技能，按阶段发言和投票；屠边计数为平民。不得读取上帝身份、私有技能和未公开死亡。

## seer

预言家 / Seer：每夜选择一个存活目标，兼容当前自验和重复查验；得到本板定义的阵营结果，仅本人获知。普通狼查为狼人，普通好人查为好人；特殊角色与第三方的登记需要角色自己的明确标签。夜间伤害统一结算前仍可执行当夜查验。

## witch

女巫 / Witch：默认解药、毒药各一瓶，同夜最多一药；主动不用药不消耗。解药只可救当夜有效狼刀目标，必须存在并符合本轮资格；毒药只可选存活目标，可自毒。自救由板子选择禁用、首夜或始终。解药耗尽后不应再获刀口信息。错误提交不得消耗药或结束仍然开放的有效行动窗口。

## hunter

猎人 / Hunter：默认一枪。狼刀、放逐或枪击死亡可开枪，毒、殉情、梦亡或决斗死亡不可开枪；复合死因含毒则禁枪。枪击来源为枪而非狼刀。本AWA版本允许末神开枪，完整死亡链结束后再按本板优先级判胜；这项选择不等于所有赛事版本。可以提交明确的空枪（无目标）消耗一次机会；非法目标不消耗，回合错误/超时按有界回退处理，不允许重复生效。

## guard

守卫 / Guard：可自守、空守，不能连续两晚守同一个目标；空守打断连续守护记录，无效提交不改历史。基础守护只保护狼刀，毒药不被守护或解药阻挡。同守同救的本板默认冲突取消狼刀防护，但毒仍独立结算。

## idiot

白痴／愚者 / Village Idiot：首次被放逐翻牌免死并失去投票权，仍可发言；翻牌后不可再次被选为放逐目标，也不可投票、竞选或继承警徽。若持有警徽，则按本AWA自动转移规则选择最小存活座位的合格玩家，没有合格玩家则销毁；权重沿用本板配置。其他死因正常处理。

## 公共流程的冻结选择

- 没有人上警、全部退水或没有有效警长票时无警长，不擅自恢复已退出候选。平票按本板选定策略裁决。
- 放逐时警徽处理、遗言、死亡动作顺序必须一致地记录；基本规范使用初批遗言、警徽处理、死亡技能与追加波次，再检查胜负。翻牌免死不是死亡。
- 同一波死亡先更新所有死亡状态，再决定合法死亡技能。胜负检查不截断已授权的链条。
- 同时达到“全狼出局”与对立胜利时，基础规则优先好人胜；其他个人/第三方目标必须显式规定优先级。
- 屠边板子起局必须同时含狼、神和平民；人数优势不默认替代屠边，只有在板子明确列入条件时启用。

## 已知实现差异与关闭条件

| 差异 | 修复阶段 | 回归要求 |
| --- | --- | --- |
| 解药未校验刀口/存在/存活，解药耗尽仍知刀口 | P4 | 非刀口、999目标、空刀、无解药均明确处理，无错误消费 |
| 同守同救分支漏算毒 | P4 | 守+救+毒、有/无狼刀，毒来源保留且猎人不能因漏源开枪 |
| 无条件末神禁枪、硬编码神职、枪击记狼刀 | P4 | 各胜负模式与死因对应动作/判胜顺序，来源正确 |
| 自爆启用窗口与校验不同，空窗口不能关闭 | P4 | 每窗口、关闭、并发裁决、警徽/死亡链闭环 |
| 转移警徽后写死1.5票权 | P1/P4 | 配置票权在赋予/转移/销毁后保持语义 |
| 白痴重复放逐免死、选举强制恢复候选等兼容行为 | P4 | 选择明确AWA参数/版本，迁移说明与空候选/零票场景 |

当前差异不构成规则规范。代码修正和独立审查后更新登记状态与测试引用。
