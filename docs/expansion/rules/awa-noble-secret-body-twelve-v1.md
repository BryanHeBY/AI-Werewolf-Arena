# AWA 觉醒之夜十二人板（实施草案）

状态：planned；角色 `night_noble` 与前置的 `awakened_idiot` 尚未交付。联合政策拟为 `awa_noble_secret_body_v1`，先扩展既有猎魔人的有限板资格，再实现本板。不得直接放开猎魔人与所有新角色混搭。

## 来源与分歧

2026-10-11 核验：

- [网易 2022-11-02 公告](https://langrensha.com/news/official/20221102/26904_1050315.html)：十二人含贵族、3 普狼、4 村民、预言家、女巫、猎魔人、觉醒愚者。贵族第二夜起设夜仆，隔夜黎明到期；已有夜仆时不能再设。猎魔命中夜仆则解除，双方不因本次狩猎死亡。秘密之身在免放逐或实际抵消一次夜伤后消耗；所选者没有待挡伤害时转护自己。
- [2022 社区板型说明](https://www.bilibili.com/read/cv19917339/)与[2024 社区汇编第 67 楼](https://forum.gamer.com.tw/C.php?bsn=37190&gothis=3189&page=4&snA=992)：补充贵族入狼队、可自爆／自刀，夜仆不知自己的状态，原阵营技能不变；秘密之身可挡夜仆伤害。作为二级资料使用，不冒称官方法典。
- [烂柯游艺社“觉醒之夜”](https://lanke.fun/extention-templates/)明确采用另一条款：贵族既不能自爆，也不能成为刀杀对象。本项目只采纳该差异为可选政策，不声称完整复刻其阶段和其它角色规则。

**必须公开的可配置分歧**：`roles.night_noble.wolfActionPolicy` 支持 `standard`（默认：按普通狼规则自爆、可成为刀口）与 `no_blast_no_self_knife`（贵族不能自爆，任何狼刀不能选贵族）。两者均入普通狼队、互知身份、参加狼聊及普通刀投票；普通狼权限不变。觉醒愚者另有 `roles.awakened_idiot.protectionRepeatPolicy`：默认 `awa_nonconsecutive_nights_v1` 采用上述社区说明的连续夜禁同目标；显式 `awa_repeat_v1` 是本项目允许重复保护的 AWA 变体，不冒称网易默认。前者按实际夜序判定，明确空过打断连续，不能用“上次曾保护”禁止隔夜再选。两项政策组合提供四份精确十二人示例与双语规则提示。公开配置解析、bootstrap、前端编辑器及严格 Tape 必须接受同一范围。

## 固定继承参数

屠边，神职计觉醒愚者；死亡隐藏身份、初始死亡波遗言。首日沿猎魔板先完整公布夜死再进行警长选举。警长开启，提名／退水／警下票／一次 PK、票重 1.5、持有人移徽；警长与放逐平票无放逐，狼刀平票取最小号码。放逐为一次 PK。仅 `on_pre_election`、`on_pre_vote` 开放普通狼自爆；贵族按上述政策。

女巫禁止自救、持解药时见原刀口、每夜最多一瓶；预言家存活目标必查；猎魔人第二夜起、原生毒免、命中好人反噬等保持已冻结语义，唯一新增例外为夜仆解除。无守卫、枪、复制、赠予、复活、第三方或其它扩展组合。

## AWA 确定夜序

夜初先投递上一夜的已告知状态并冻结原生命／库存 → 原生药重置 → 身体主动保护（150）→ 狼聊（200）→ 普通狼刀票（400）→ 贵族选夜仆（450）→ 女巫（500）→ 预言家（600）→ 猎魔（650）→ 清除／到期独立来源与救活、毒免过滤 → 身体抵消 → PM 完整死亡结算。括号为唯一阶段优先级，不能依赖同优先级字符串排序；首夜跳过贵族和猎魔，但身体可用。旧夜仆在其到期夜的贵族选择窗口仍占位，随后才可能被猎魔解除或到期。

## 夜仆与延迟伤害

1. 第二夜起，贵族可选一名其它当前存活玩家（含狼队友），或明确跳过；同一贵族至多一个待到期夜仆。有待到期夜仆时不发新的选人请求，不虚构 pass。
2. N2 建立的夜仆在 N3 完整夜结算到期，N2 不伤害。若未提前解除或目标死亡，N3 选人窗口仍被占用、最早 N4 重选；若 N2 已被猎魔解除或目标 D2 真实死亡，则 N3 即可重选。夜仆的角色、阵营、能力、刀权均保持。
3. 贵族选择先于当夜猎魔，猎魔既可解除旧夜仆，也可解除同夜刚建立的夜仆。解除替代本次狩猎的杀狼／反噬；不会挡掉目标另受的刀、毒或其它独立有效伤害。无论夜仆阵营，猎魔人都不能从该次结果得到查验信息。
4. **AWA 到期裁定**：到期先关闭这条契约，再提出一次独立夜仆伤害；即使被秘密之身挡住，也不会下一夜重复到期。关闭与来源提议属于同一个同步领域提交并一起录入 God operation；若在其后、实际夜伤前失败，保留 expired 及已提议来源，不恢复契约、不重复到期，未实际抵伤不消费身体，也不伪造 night_resolved。夜仆提前真实死亡时关闭契约；贵族死亡不倒销已提交的契约。无复活板，不能把同 ID 的新生命接到旧契约上。
5. 贵族若作为末狼死亡，仍按正常完整死亡链判胜，不为未来夜仆额外开一夜。游戏已经结束时不会离线追加到期死亡。
6. 所有契约绑定原贵族实例、目标原生命、建立夜序、到期夜序和唯一状态。跨夜 pending 由单一领域 owner 持有，与每夜动作租约分离。状态只从 pending 到 cleared／expired／target_dead；贵族合法死亡不使已提交契约失效，原生命或实例替换也不能转挂。失败、重入和迟到不能重复消费／创建，同夜不得重新打开已经结束或失败的选人、保护或到期操作。

## 秘密之身与 AWA 伤害次序

- 初始一份秘密之身。持有时每夜可选一个存活玩家（允许自己，能否重复上一夜按公开政策）或明确不指定；未指定时只保留当夜自护机会。未实际抵伤不消耗，目标选择本身不消耗。连续限制只记录主动指定目标／明确空过；无伤后的自动转护自己不改 lastTarget，不把合法空过记成主动连续自守。
- 每夜先处理女巫救活及猎魔原生毒免、夜仆解除，再计算仍然有效的独立伤害。对指定目标抵消恰好一个来源；若目标没有有效伤害，改为对觉醒愚者自己尝试抵消一个。指定目标实际挡过一次后，不再转护自己，即使目标仍有第二个来源而死亡。
- 多来源的 AWA 固定先后为：普通狼刀、女巫毒、猎魔命中、猎魔反噬、夜仆到期。只从真正有效的来源中移除第一项。秘密之身覆盖这些夜伤，但不是整夜无敌；不引入未验证的白天枪／梦／反弹组合。
- 保护在同夜伤害提交前成立；觉醒愚者自身当夜死亡不倒销已提交的保护。它的原生命／技能实例在请求 await 中被替换，则旧选择撤权；不可凭 playerId 给替代实例消费库存。
- 白天最终放逐对象为仍持有秘密之身的觉醒愚者时，自动公开角色、消耗身体并免掉这一次放逐。**AWA 翻牌后权利裁定**：保留正常投票、竞选和警徽资格；下一次仍可被放逐。不套用原生白痴的永久免放逐／失票逻辑。按社区说明提供一次公开翻牌发言，命名独立阶段 `awakened_idiot_reveal_speech`；不是死亡遗言，使用独立活人翻牌事实（不能复用当前 reader 同时解释为死亡的 `player_role_revealed`），不调用死亡钩子／移徽／Alive 修改，不允许插入自爆。发言缺失／迟到保留已翻牌及已消费事实并保存失败前缀，不伪造完成；其后的正常白天仍保留发言资格。
- 夜间抵伤后失去身体，不再有免放逐机会，也不再收到保护请求。白天翻牌后同理。夜间实际库存即时消费，知情通知延至下一夜，详见受众段；不公开底牌或受保护者。一次实际抵伤即消耗，即便剩余伤害仍令目标出局。

## 受众与终局

受众和通知时点分开：God 立即记录真实契约及身体库存；玩家信息只使用独立的已告知投影。

- 贵族立即知道自己的合法选择，猎魔清除／目标死亡／到期后的契约状态在下一夜开始、决定是否发新请求之前统一告知。死亡的贵族不追加私有通知。夜仆本人和普通狼同伴不知道目标／倒计时。
- 猎魔人沿 `demon_hunter_chosen` 只获自己的原始选择；不报夜仆状态、解除成功、阵营或实际伤害成败。
- 觉醒愚者知道自己的选择；夜间是否实际耗身，下一夜开始才统一告知，无论该夜是否已没有技能请求。白天明确标作“本夜是否消耗尚未告知”，不能输出虚假的当前库存值，也不能从通用能力 DTO／schema／错误／状态摘要旁路读取 raw 剩余量；尤其 uses、lastUsedDay、disabled、status、可见能力列表与文本 maxUses−uses 都须经过同一知情投影，不能只藏 state.remaining。白天自己翻牌时的耗身是已公开事实，可立即更新本人知情。
- 受保护者不收到施法者或抵伤通知。身体／契约的 God operation 不自动进入玩家 feed；已告知历史与实际状态均独立记录、逐 checkpoint 验证。
- 最终死亡、真正翻牌、票权与警徽按实际发生公布。不得用私有到期或库存事件提前改变前端 Alive。

PM 持有夜推进、统一公开夜死和最终判胜；DeathResolution 持有真正死亡、遗言、警徽与追加链。夜仆契约不能自行切阶段或设置 winner。

猎魔人扩展必须贯通其原身份／阵营白名单、实际狼刀 source owner、原生命/能力授权、允许变更的同步审计快照、原生库存及独立 Tape 死因集合。新角色的创建、清除、到期、保护选择／消费及翻牌分别提供明确域提交；禁止用“刷新全部当前 privateState”掩盖越权改写。现有四份猎魔板及赤月的资格保持，只枚举本卡四种组合；不能仅通过 preset 后在 authority 或 Tape 中仍拒绝新贵族。失败前缀保存已提交契约／消费，未完成夜伤不可假造 night_resolved。本板新技能、猎魔、翻牌专属发言及必答狼聊／刀使用 error/no fallback；普通日间发言、选举、投票与可选自爆沿既有策略。不自爆是合法决定，不能把它当必答失败；既有四份猎魔板不因此改成严格狼阶段。

## 必须手写的判例与提交边界

1. N2 设置、N3 到期、N4 重选；N1 无贵族请求；另测 N2 创建→N2 清除→N3 新建，以及 N2 创建→D2 目标死→N3 新建。
2. 同夜新夜仆与旧夜仆，各由猎魔解除；目标分别为好人／狼人，双方无该次猎魔伤害；同时刀／毒不被解除吞掉。
3. 到期被身体抵消，契约仍结束；到期与毒双中，只挡一个且身体用尽；到期后无重复伤害。
4. 所选者未受伤／普通刀被女巫救起，身体转护自己。手写：所选 A 刀毒双中、愚者 I 夜仆到期，只移除 A 的刀，A 仍毒死、I 仍到期死，身体消费一次且不转护；另两例分开验证以遵守女巫一夜一药：A 的刀被救且无其它伤、I 仅夜仆到期，自动转护抵消到期且 I 存活；A 完全无伤（普通刀给 C）、I 同时毒与到期，只移除 I 的毒，I 仍到期死。
5. 猎魔毒免先过滤，不能让无效毒消耗身体；猎错好人的反噬可以被身体抵消，原好人仍无猎魔伤害。
6. 禁连模式：N1 主动选安全 A→自动自护未抵伤，N2 可主动选自己；N1 明确不指定→自护未抵伤，N2 再空过合法。自动回退不覆盖主动目标历史。
7. 未花身体的免放逐与已花身体的真实放逐；翻牌后下一天投票、持徽及再次被放逐，均用真实 pipeline 验证。
8. 四种组合分别验真实连续夜目标、空过后再选，以及两种贵族政策的 wolf chat／knife、自刀目标、自爆窗口；禁用版本对其他狼人权限无影响。
9. 贵族死亡后契约到期、末狼提前终局不再到期；目标生命或契约原实例跨 await 更换时旧请求不提交。
10. SDK／ACP／混合 × 中英的完整局及严格 missing／late，秘密目标不出现在其他玩家 system、current、事件、错误和 MCP 响应。
11. 真夜消费后至下一夜通知前，检查 SDK／ACP 提示、玩家档案、MCP、工具错误及前端私有视角均没有 raw 库存／清除旁路；God 保留真实状态，通知不影响机器死亡或资源。翻牌发言无死亡、遗言或徽章操作；持徽者 Alive=true、票重 1.5 保持，发言失败也不改成死亡。逐帧检验白天 n 和夜 n+1 通知前后的能力列表、metadata、schema、错误和私有画面；死者或已终局不补通知。
12. 独立账本拒绝提前到期、重复到期、解除后伤害、跨生命挂接、库存补回、免放逐与伤害重复消费、伪造票权以及无资格 error/pending 请求。前端／终端／Remotion 在选定、清除、到期、真正死亡与翻牌各帧一致。
