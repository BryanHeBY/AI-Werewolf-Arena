# 原生狼王白天死因开枪策略

状态：implemented；限定原生狼王及已验证的魔术师有限板。功能与兼容性证据见[验收记录](../reviews/p9-wolf-king-day-policy.md)，P9c 阶段全量及 P10 仍开放。

## 来源与命名

2026-10-11 核验 [LAL 狼王魔术师规则](https://werewolves.games/lang-wang-mo-shu-shi/)：狼王的开枪资格包含死亡昼夜限制，还另有最后一狼限制；猎人也有最后神职限制。[Local Hunt 魔术师](https://werewolf-local-hunt.com/zh/role/magician/) 则描述夜死猎人／狼王的枪受到换位影响。因此“可否开枪”和“枪口如何映射”确实是两项独立规则。

本次增加 `roles.wolf_king.deathActionPolicy = awa_day_deaths_v1`，仅采纳死亡来源昼夜这个局部差异，明确是 AWA 组合规则，不声称复刻 LAL 全部规则。旧默认 `awa_qualified_sources_v1` 与已有 `awa_knife_or_exile_v1` 均保留。猎人、复制枪、商人赠枪不接受或继承这项新原生狼王配置。

## 确切行为

- 身份、阵营、狼队权限、自爆、次数均不变，仍是一发原生死亡枪。
- 新策略先要求全部死因通过既有 qualified 白名单，再要求死亡来源是白天；毒杀、刀毒复合、决斗、自爆等原本禁止的来源不因白天而放行。
- qualified 白名单为 `wolf_kill`、`mechanical_knife`、`awakened_hidden_knife`、`exile`、`shot`、`white_wolf_blast`；原因集合非空且每项均合格才可通过。
- 放逐阶段 `Voting` 属于白天。首夜死亡即使在警长选举后才公布，仍属于夜死；夜间死亡引发的追加枪链也属于夜死。
- 同一死亡批次混入有明确白天来源的自爆，不因周围夜死亡而改成夜死。
- 同一狼王兼有尚未公布的夜刀与白天白狼王带走等原因时，若结算保留明确 Day 来源且全部原因合格，则按白天允许开枪。这是 AWA 的来源优先级裁定，须独立于“同批不同玩家各有昼夜来源”验证；混入毒等禁用原因仍否决。
- 判定缺少死亡来源时，新策略拒绝开枪；旧策略保持原 API 的因果判断。
- 不能开枪时不请求玩家动作，按现有原生枪流程结束该资源；可以开枪时仍允许显式空枪，非法或晚到回复不能产生效果。
- 最后一狼的白天死亡仍先完成当前 AWA 死亡连锁，再由 PhaseManager 判胜。此条与 LAL 完整规则的差异必须出现在规则说明中。
- 魔术师 `deathShotTargetPolicy` 独立控制落点。夜死禁枪时，两种落点策略均不得借映射获得开枪资格。

## 所有权与配置闭环

DeathResolution 在每位死者处理时解析一次来源阶段：首波明确阶段优先，其次夜间来源链，最后该波阶段。通过不可变 `deathOriginPhase` 交给死亡 hook；新政策的枪请求提供 `death_origin_phase`。父枪资格来源只在真实击杀同步提交时写入目标 originMap，落空、保护、撤权不创建起源。World actions.phase 继续只管执行授权。

纯资格判断接收来源阶段，hook 请求前、回复后、World permit 与延迟落效果前使用一致语义。**兼容边界**：既有 request.phase、legacy death_phase 和魔术师原 nightExchange 计算保持；新来源不覆盖梦境的 nightOrigin 会员。混合 Day+Night 死者仍有原夜梦保护／牵连，后代可以同时具备 Day 枪资格和 Night 梦效果。普通纯 Night 枪链的新来源仍是 Night，哪怕旧 death_phase 在追加波标作 Day。来源或策略在等待期间改变须撤权。保持现有资源和死亡唯一负责人，不另建死亡框架。

狼王配置枚举、schema/default/apply/serialize、初始化、玩家 DTO、中文／英文提示、公共规则、魔术师有限预设、录制独立账本及严格重放均需同步。旧默认快照和复制／赠予枪语义保持兼容；源码指纹变化仍正常使旧严格 Tape 不兼容。

## 人工判例与提交门槛

1. 原生狼王夜刀死亡：默认请求枪，新策略不请求；首日先上警不改变结果。
2. 夜死猎人枪杀狼王：当前执行阶段为 Day 时，新策略仍不请求。
3. 白天放逐、白天合格枪击或白狼王带走：新策略可请求；复合禁用死因仍否决。
4. 同批混合昼夜来源、来源缺失、await 期间策略／死因变更、延迟落效果前撤权。
   另覆盖同一狼王兼具夜刀与白天带走原因，验证上述明确 Day 优先裁定；混合来源猎人→新策略狼王可得 Day 资格，但后者枪击夜梦保护目标仍落空／消费，保留所有旧 Dreamer 判例。
5. 两种魔术师落点政策与新旧资格交叉运行，明确末狼的 AWA 连锁顺序。
6. 猎人配置新值拒绝；复制枪、赠枪回归；默认省略／显式值往返一致。
7. 双语完整游戏、SDK/ACP 本地通路、严格 Tape，拒绝伪造来源、政策或为夜死狼王插入枪请求。

按 delivery 的 R/A/T/L/D 交叉审查和功能门禁提交。此草案不修改 P9d–P9f 的角色数量。
