# review release activity driver

## 1. 当前代码详细文档

本文件定义 V3 研发中的发布前后自检活动驱动，确保“可读、可测、可回滚”。

发布前自检活动：

1. 规范对齐检查：是否对应白皮书/MVP 条款，是否超出当前阶段范围。
2. 架构边界检查：是否破坏串行状态机与 ECS 边界。
3. 测试覆盖检查：是否新增/更新对应测试，是否覆盖关键回归点。
4. 文档同步检查：`docs/guides` 任务状态与源码中文注释是否同步更新。

发布活动（里程碑/版本）：

1. 冻结变更范围：仅纳入已通过验收标准的任务。
2. 执行回归清单：先规则正确性，再联调与性能冒烟。
3. 生成发布记录：变更摘要、风险点、回滚策略、观察指标。
4. 发布后观察：收集异常日志与规则争议案例，回灌文档。

最小发布清单：

1. 关联 specs 条款编号。
2. 关联测试报告或结果摘要。
3. 关联源码变更文件清单。
4. 回滚入口与触发条件。
