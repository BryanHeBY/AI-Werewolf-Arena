# activities 索引

## 1. 当前代码详细文档

本目录存放“面向执行流程”的活动驱动文档：

1. 开发活动驱动：`development_activity_driver.md`
2. 测试活动驱动：`testing_activity_driver.md`
3. 评审与发布活动驱动：`review_release_activity_driver.md`

定位：

- 适合做“任务如何推进、如何验证、如何发布回滚”的入口。
- 与模块驱动互补：活动驱动负责流程闭环与质量约束。

## 2. 开发任务清单

- [ ] `T01` 开发活动：实现阶段性代码改动（phase/gateway/memory/server）并同步任务状态。
- [ ] `T02` 测试活动：新增与更新 `backend/tests/v3/*` 回归测试并执行验证。
- [ ] `T03` 发布活动：执行本地发布前检查、会话冒烟、回滚路径验证并记录结果。
- [ ] `T04` 真实模型活动：使用根目录 `.env` 的 Minimax `OPENAI_*` 配置执行一次连通与 tool call 最小回路验证。

## 3. 验收标准（任务映射）

- [ ] `A01`（对应: `T01`） 每项开发改动都能对应到具体测试与验收项。
- [ ] `A02`（对应: `T02`） 关键规则测试可重复通过且输出明确结论。
- [ ] `A03`（对应: `T03`） 发布前后检查记录可追溯，回滚路径已验证。
- [ ] `A04`（对应: `T04`） 真实模型连通测试可重复执行，失败时能输出可定位原因且不泄露密钥。
