# 真实模型评测

离线规则测试、本地合成 SDK／ACP／MCP 通路、浏览器与媒体验证不代表真实模型的策略质量、成本或延迟。是否完成某次模型评测，以该次明确配置和实际运行记录为准。

## 执行前准备

- 选择已支持的板子、语言、固定种子和玩家 Agent；明确模型、接入方式、版本、账户与重试设置。
- 指定局数、并发、单局／回合时限、输出长度和总费用上限。总费用使用账户或专用项目的实际硬额度控制，不能用并发或 `maxTokens` 冒充。
- 使用独立配置目录，只复制需要的 board 和 game。认证沿已授权的环境变量或单个只读文件提供，不批量读取或覆盖个人配置。
- ACP 使用[隔离启动器与合成 canary](../../configs.example/acp/README.md)复核最终挂载；God 归档、日志及其他玩家目录不挂进玩家沙箱。
- 配置和预算准备到可审查状态后，由操作者明确启动。真实模型调用不作为日常离线门禁的隐含步骤。

```bash
# 只验证配置；不启动 Agent，也不验证账户额度或模型可用性。
bun run --cwd apps/game config:check --configs-dir /ABS/PATH/isolated-evaluation --game-config-name selected_game
```

## 运行与结果

先单局验通，再按确定的批次执行。达到费用或时限、出现认证／限额错误或隔离失败时停止对应批次；失败不自动换账户、提高预算或计作有效样本。

记录源码与锁文件身份、板子、种子、模型／adaptor 版本、语言、实际账单／用量、回退、错误和耗时。核对工具发现与真实提交、秘密通信的受众、超时后的回合与进程回收，以及同构建严格复现。

按实际启动数统计，重试和严格复现不算额外模型样本。未完成局如实保留；成本、延迟、发言自然度和策略质量分别报告。公开材料先按[隐私维护约定](repository-hygiene.md)处理，God 回放不作为玩家权限证明。
