# 发布候选真实模型评测

这是T6的可审查执行提案，**当前未授权、未执行**。本轮合成SDK／ACP／MCP、操作系统canary、浏览器和媒体门禁均不计作真实模型成绩。实施其它已授权任务无需等待T6。

## 建议批次与预算

| 项目       | 建议值                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------- |
| 板子       | 乌鸦、禁言长老、典狱长、觉醒女巫（含觉醒狼王）、十／十二人暗夜星辰、觉醒骑士原板，共7种                       |
| 语言与种子 | 每板中文／英文各1个预先固定seed，共14局，不自动重跑失败局                                                     |
| Agent      | 每板同一组已选定SDK模型与隔离ACP adaptor，按奇偶席位混用；具体模型、Provider／账户须在执行前具名确认          |
| 并发       | 每Provider最多2个请求；先单局验通再串行运行余局                                                               |
| 单局       | maxDays=12，maxRuntimeMs=600000，llmTimeoutMs=45000；SDK maxTokens=1024                                       |
| 金额       | 建议总硬上限20美元；必须在实际Provider账户／专用项目设置有效硬额度后执行，不由本地并发或maxTokens冒充费用上限 |
| 终止       | 费用额度、单局时限、真实限额／认证错误或隔离canary失败即停止该局，不自动换模型／账户或提高限额                |

这是预算方案，不是模型价格估算。SDK保留代码中现有传输重试和工具循环，多个HTTP调用仍共用原回合deadline；本提案不把“一局”或“一回合”说成“一次计费请求”。ACP内部模型重试也受所选adaptor配置约束，需要一并记录。

## 独立配置

在操作者选择的独立目录准备`runtime/providers.json`、`runtime/agents.json`、所选公开`boards/<id>.json`和`games/<name>.json`。只复制选定板／game，不读取或批量覆盖已有`configs/`。Provider认证只从专门授权的变量或单个只读认证文件获得；日志、God归档及其它玩家目录不挂进ACP沙箱。

实际SDK模型名称和URL、ACP可执行文件及版本、只读依赖与具名环境白名单、认证来源、14个seed、费用额度、单局限制及输出目录应形成一份执行清单。使用[公开隔离模板](../../configs.example/acp/README.md)的合成canary复核最终挂载；新增挂载不沿用模板已测结论。启动前先执行仅检查的入口：

```bash
bun run --cwd backend config:check --configs-dir /ABS/PATH/isolated-evaluation --game-config-name selected_game
```

此检查不启动Agent、不检验账户额度或模型可用性。只有操作者随后明确授权上述最终模型／配置和预算，才运行真实对局。

## 记录与验收

每局保留源码／lock身份、板子和实际seed、模型／adaptor版本、locale、完整失败与限额原因、真实账单／用量、回退和耗时统计。原始God和逐玩家导出分别审查；公开报告去掉凭据、个人路径与原始人格。局数用真实启动数统计，不把失败重跑或严格复现计作额外模型样本。

核对新工具发现、纠错、真实行动是否提交，秘密交流／God结果是否泄漏，断线／超时是否收回回合与子进程，以及正常／失败录制能否在同构建严格复现。成本、延迟和玩法质量与离线规则正确性分别报告。达到费用或时限的未完成局如实记未完成，不提高预算求通过。
