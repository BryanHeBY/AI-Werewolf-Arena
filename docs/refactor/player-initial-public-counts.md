# 开局公开配比观察边界

游戏观察模块完整拥有公开角色配比的三种来源：盗贼／千面人初发牌候选优先，其次聚合板子配置，旧无板子调用按开局实际角色统计。AI 策略继续唯一持有人数、公开配比 Map、模板和人设。
