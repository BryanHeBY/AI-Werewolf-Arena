## 关键逻辑与结构

数据复制按自有数据描述符读取，拒绝访问器、Node Proxy、符号键、循环及超限数据。`seen` 是当前递归路径，finally 无论成功失败都退出本次路径，因此非循环重复引用会分别复制。普通对象副本字段默认不可写、不可配置，数组输出仍为新的普通可写数组；两者不构成原体身份或提交许可。

故障计划先复制数据，再由 schema 校验单步、标识唯一性和严格递增日期，最后深冻结副本。字段读取不执行 getter；这个模块不运行故障或修改 World。它与普通复制对 `__proto__` 和数值原样传递的处理差异分别说明，没有新增输入拒绝。

随机流使用既有 JSON 路径和 UTF-16 码元算法。trim 只检查种子／名字非空，原字符串继续参与算法；同名 fork 不消耗父流。抽样包装晚读 next 并保方法接收者，Fisher–Yates 每轮只抽一次且仅写新数组。算法／策略标识、默认 UUID 和序列保持。

玩家身份是可写资料，稳定会话字符串不是行动凭据或跨局认证。阶段表与角色工具表保存／返回数组副本，保顺序及重复项；登记资料不代替真实请求、资格或工具验证。
