C39／C40 本切片补齐另外两类录制文件的版本声明。它保持原文件、刷盘和内存聚合职责，没有新增玩家复盘界面或为了读取清单创造生产 I/O。

| 文件 | 新声明 | 历史读取 |
| --- | --- | --- |
| `manifest.json` | 原根字段追加内联 schema 1 与身份 | 无版本清单保留原字段及身份缺席 |
| `players/player_*.json` | envelope 1，kind 为 `player_view`，内层 schema 2 | 无声明／1／2 沿原玩家 reader 转换 |

清单的形状和 codec 归纯归档契约；后端只保原 enum、判胜和 RNG 类型收窄。manifest 的 seed 仍是私有字段，公开及玩家封装身份不包含 seed。初始来源为 `null`；建立 Trace 后按原下一次发布时点使用同一捕获来源，不额外触发 dirty 或写盘。

玩家 reader 实际拒绝未知外层及请求／展示声明，同时保留 prompt、工具、原文和玩家局部序号。审计与调试继续使用原内存 manifest 和玩家 schema 2，不把磁盘封装混进聚合状态。

中立展示协议常量归 `game-contract`，实际 renderer 支持判断仍归 `game-presentation`。归档包声明直接契约依赖，lock 只增加该 workspace 依赖，外部版本与 integrity 不变；不反向导入 renderer 或 backend。
