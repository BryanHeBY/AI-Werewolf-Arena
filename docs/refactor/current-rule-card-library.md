# 现行规则卡归属

C43 的第一笔将 43 张现行规则卡从扩充交付目录迁到 `docs/rules/`。规则版本、角色 ID、正文、链接标签及全部外部来源 URL 保持；扩充历史和验收证据仍留在原目录。

`game-catalog.ruleCardRef`、15 个源码／测试职责引用及文档链接同步使用新位置。新增规则索引与文档首页入口区分当前规则和扩充历史。没有将历史验收说明扩大为所有玩法组合已经支持。

## 路径与内容验证

- 136 个既有 Markdown 文件的完整正文仅改变链接目标，43 张卡片包含在其中；外部来源地址逐字相同。
- 967 个链接按迁移映射核对；除基础卡三个已失效测试链接改指当前主要单元边界外，其余解析目标保持相同。
- 规则卡及两个入口的 90 个本地链接均指向实际文件；64 项角色资料中 55 项非空规则卡引用及锚点有效，九项 planned 保留空引用；资料登记不等于执行支持。
- 16 个源码／测试完整程序在只逆规则目录前缀后，32 项运行输出相同。目录模块职责头准确译成中文，角色 ID、规则版本与其他字段保持。
- 文案目录包的独立类型检查通过，16 个触及源的真实职责检查无诊断。没有为文档路径重复运行对局、模型、旧测试或全量门禁。

当前资料引用的公开路径有意改变；路径和注释仍进入真实 sourceHash，历史指纹不改写。旧路径作为历史文本和冻结证据的记录可继续保留，活动链接及源码引用使用新目录。
