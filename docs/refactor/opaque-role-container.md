# 核心角色容器保持不透明

`RoleComponent.privateState` 的公开类型改为 `object`，实际工厂、对象、描述符与原指针保持。读取方通过具体机制或库存入口获得有限状态视图，核心不再提供可枚举键的通用 Record API。Profile 初始化继续使用已有可写契约，支持任意扩展键和容器替换。

实际 owner 的原属性访问使用具体只读槽位或整容器检查视图；不创建影子状态、不增加通用 get／set，也不把旧描述符、JSON 或原体检查替换为普通 getter。已有失配、首次死亡和权限逻辑保持。

外部原始读者按实际职责收口：Eclipse 经过原严格投影，Mist 三处读取保持原可选／必需角色差异，贵族读取保持原条件，retired ability IDs 保留原数组或缺失时的新空数组。归档仍按原 precedence 选择状态，类型断言仅位于原 `structuredClone` 结果之后。

本批为 68 个路径：33 个源码、34 个既有测试及 1 个新测试。39 个具体源码视图、93 项测试类型适配保持原表达式、指针、左值、值、回调和断言；五处显式初始化调用仍经过原 init，未用生产 setter 替换造数。29 个测试来源直接核 Git，四个 support 迁移快照和一个上下文快照明确登记为并行输入。

完整源码／测试程序和存储身份核对通过；新增三个局部测试 3 通过、0 失败、11 项断言。最终多批后端类型检查通过，独立审查核对最终摘要、旧授权及 13 个归档／schema／初始化控制。详细来源和结果见[证据](generated/opaque-role-container-evidence.json)。完整 schema／编码、旧门面退出及最终全量验收继续执行。
