## 真实边界

- 运行预设只提供原 `BoardConfig` 数据。常量不因此深冻结；贵族秘身工厂仍每次构造新配置。旧六人／十二人 resolver 显式复制和规范化指定容器，不能由这些预设推断任意角色组合受支持。
- 生产支持谓词按各自字段、牌组、唯一性、胜利目标及政策判断。猎魔人、魔术师和定序王子保原有限组合委托顺序；定序王子基础分支未被描述成严格全字段 schema。动物梦境四候选、贵族秘身四政策组合和赤月两政策组合分别注明，不扩支持集合。
- `boardPresetViolation` 保首个违规的分派顺序。猎魔人 Node 入口先做自有数据快照，原深度、数组限额与失败转 `false` 保留；共享数据复制本身不被称为敌意 Proxy 安全入口。
- 阶段登记按原 handler 同引用去重，保新登记的第二次 ID 求值。鬼魂新娘四步替换、Map 写入后记录、失败不回滚前缀均保。工具 schema 只比较完整自有数据的结构；不透明覆盖仍是原接受面，不冒语义等价、已验证安全或动作许可。
- 原生夜间策略的 World／context／day／target 沿原委托晚读，不缓存权限。目标和回执 `readonly`／`Omit` 只是类型视图，实际对象及运行字段未复制、冻结或删除；查询不等于回执付款。
- 归档支持判定仍拥有独立本地实现和中立数据契约，不导生产谓词作 oracle。数据 schema 合法、有限板子支持与真实行动授权是三个不同判断。本批未新增归档拒绝政策或更改历史规则。
