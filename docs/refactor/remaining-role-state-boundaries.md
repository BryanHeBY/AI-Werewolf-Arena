# 其余十五族角色状态的读取边界

本批覆盖丘比特、混血儿、野孩子、盗贼、变脸者、辩论家、恶灵骑士、梦魇、魔术师、捣蛋鬼、狼巫、时间狼妃、师徒、孤独少女及赤月使徒。原 31 个公开数据声明集中到已有 `role-state-data.ts`，新增 18 个有限读取别名；没有新增按角色映射的全局存储或逐类型文件。

十四个返回原存储引用的 getter 保留原有描述符、Proxy、历史及形状检查。深层选择、配对元组、库存和历史表达只读约束。师徒的 `readModifierState` 继续返回可写的独立归一化副本；真实槽位和捕获引用使用读取类型。其他工厂、解析副本和玩家投影的复制行为保持。

实际生命周期、阶段和授权 owner 在原位置恢复 33 个具体字段的写权。原检查、资源支付、发布和失败前缀不变；猎魔人的赤月结算仍经过原封印授权。归档中独立推导的师徒类型没有合并到生产算法或资源视图。

九个既有损坏状态写入仅添加具体字段的类型断言，原 getter、左值、值、回调和断言保持。新增三项测试检查丘比特原引用与配对、魔术师原存储与独立投影及零 accessor 读取、师徒原槽位与可写副本，并提供十五族有效字段的编译期禁止写入检查。

本批为 46 个路径。31 个原声明、44 个已有声明／读取别名、62 项双向类型赋值和 45 个完整原运行程序核对；新增测试 3 通过、0 失败、17 项断言。最终固定源码的有限类型检查实际退出 0，原失败日志及构建工具修正分别保留。详细来源、最终文件摘要和交叉审查见[证据](generated/remaining-role-state-evidence.json)。并行生命周期与 support 的改动不计入该固定源码检查。

剩余原始键读者、核心不透明容器、完整 schema／编码、自定义贡献和旧入口退出继续按计划执行。本批没有改变归档格式、角色规则或玩家信息权限。
