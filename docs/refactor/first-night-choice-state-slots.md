## 原顺序与失败前缀

- Profile 的原同引用查询、LHS 私有容器、policy／fresh 数据创建顺序保留；配置在原表达式点由 thunk 读取，不提前取 getter。
- 千面人选新身份先 remaining、choice，再物理交换／身份安装；盗贼对应分支仍不消费旧对象。共同保留身份分支不额外查询 kind，先 remaining 后 null choice。Shape 原 finally 两 descriptor 都可写才补偿。
- 野孩子先原可写短路，再 remaining→status→choice，之后读取原 target.life 写 model，再编码／expectedState；setup/windows 标记仍在后方。取消先原窗口关闭，再数据；榜样事实、阵营／Victory 已发生后才写 transformed；active 时点仍由原夜生命周期决定。
- 孤独少女先两字段消费，再 Victory 安装与完成标记；取消先原 status/isCurrent，再逐 descriptor→defineProperty，第二字段失败不回滚第一字段。玩家知识不暴露目标 Camp，也不是全员公开状态。
- 新窄函数／thunk 增加调用栈和词法作用域，保原字段／callee读取点。字段或编码赋值失败仍保已写前缀，无新退款、catch、current、RNG 或 await。
