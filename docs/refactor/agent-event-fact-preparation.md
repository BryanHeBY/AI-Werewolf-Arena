# 玩家事件事实的统一解析准备

本 C34 切片建立一次解析的家族事实与新投影入口。生产 Node 事件流暂未切换，原布尔可见性和原直接投影入口保持；下一笔单独完成事件流切换及旧直接投影 API 退出。

## 职责

`agent-event-facts.ts` 在 Node 已拒绝 Proxy 并取得纯数据快照之后，选择唯一家族读器。读器标识与事实组成类型联合；授权和字段裁剪使用同一次解析结果。它不持有 World、回调、资源或行动许可，类型标记本身也不是安全凭据。

新入口让可信自定义规则继续收到原副本，按原分支时点查找并以原接收方调用。schema 事件的类型、规则查找键及历史受众固定在解析结果上；元信息独立复制，payload 复用原家族读器的深副本。无 schema 的事件继续保留原副本与后置来源读取语义。

旧 typed／trusted 布尔 API 保留实际较弱的接受范围，不能将其说成未知输入的安全入口。原 Node 入口的反射前 Proxy 拒绝、玩家局部连续序号和未知事件默认拒绝保持。

## 有意的新 API 约束

旧回调可以把已校验的 RedMoon `day` 改为另一值，输出与 `night` 不再关联。新 schema 投影固定已解析事实。交叉审查进一步修复 source 类型／payload 被换写后的重新读取、规则键绕过及 audience 引用共享，新增跨玩家和深层数据反例。上述约束属于新入口；不将其混入旧 API 的机械等价结论。

## 证据范围

- 三个原程序、47 个读器调用及 31 个真实导入来源完整逆向核对；六项运行输出完整解析 token 相同，其中四项原字节相同、两项仅格式不同。旧 characterization 原字节相同，生产 feed 原文件未改。
- 实际分派覆盖 98 个事件类型、31 个读器，无重复分派。31 个字面样本代表每个读器，不代表 98 个事件类型及所有受众组合都执行过测试。
- 三次有界执行分别为 13／199、3／21、1／62，合计 17 个不同用例、282 个断言，没有未关闭测试失败；不声称单次执行全部 17 个用例。
- Root 与独立审查核对新旧入口的信任边界、回调时点、字段裁剪及四个最终源码摘要。中文头与关键结构／顺序说明随实现补齐。

首次工具路径、样本类型、并行录制诊断及中间误修改导致的真实失败均保留证据与归属。四个范围根已纳入 105 根汇合有限类型检查，实际退出 0；本记录不代表全仓检查或完整可见性矩阵完成。详见 [证据](generated/agent-event-fact-preparation-evidence.json)。
