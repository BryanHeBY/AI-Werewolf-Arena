# 终端诊断工具中文契约

本批随主重构补充 `ansi.ts`、`error_diagnostic.ts`、`speech_text.ts` 三个现有工具的中文维护注释。实际前态为 `620673877a23d2e0a748b08c17ec0ca57a3cd4b9`；完整原稿和三项稳定控制保存在证据中。控制包括实际网关、终端调用方和 CLI 错误码表，错误码表不是诊断函数的直接调用方。

## 关键逻辑与结构

ANSI 的优先级是显式布尔值、非空 `NO_COLOR`、认可的 `FORCE_COLOR` 值、TTY 状态。显式 false 也直接返回；着色仅包裹控制符，不修改正文或事件数据。

错误诊断最多查看八层对象，按 `lastError ?? cause` 查下一层并避免循环。自有描述符读取不调用字段访问器，但 Proxy 的描述符 trap 仍可能执行。DOMException 使用已捕获的原生名称读取器，品牌失败后回退。后继有效 HTTP 状态可以替换已有诊断；其它候选仅替换通用传输诊断。输出只含有限诊断字段和词典说明，Retry-After 仅按现有十进制秒格式转换，函数本身不重试。

发言清洗保持原 replace→trim 次序，只去掉开头连续的保留称谓；中间同类文字仍保留，不增加字符串强制转换或异常吞噬。权限判断仍由真实网关承担。
