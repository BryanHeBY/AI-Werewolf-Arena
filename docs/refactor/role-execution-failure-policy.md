# F05a 身份失败执行退休的原子交付

本功能以实际 Git `bd2e04894509f7777d2909632f768a3329e3b57a` 为前态。四个作者分别持有安装 writer／共同集合、资源命令、野孩子与枪资格、狼队与自爆，共 13 个生产路径和四个新单元路径。它们按独立范围审查，作为同一个功能原子提交：初始身份单元的执行拒绝预期需要共同资格 reader，不能在只安装 writer 的中间提交声称测试已经完整通过。

## 唯一状态与实际边界

领域私有 WeakSet 只记录失败 Role 对象的永久执行终态，不存 Camp、World、库存或恢复值。初始身份只在候选 Role→Camp→Victory 安装段失败时退休候选；野孩子沿原核心 catch 退休原角色，保本族绑定终态。两个 writer 都用捕获引用，保原 Error、付款／换牌／组件前缀和外层清理优先级；完整核心之后的事实错误不退休已提交身份。

资源、行动请求和真实消费点各查同一拒绝信号。狼队知识、目标身体、纯数据、原库存、玩家观察、历史受众及死亡清理保原职责。夜能力 owner、赠枪纯 current、原生枪已消费延期提案仍按原生命／来源／状态规则复验。请求的执行资格和已付提案不能合并；这一区别已经写入相关中文头、关键判断和写入点说明。

## 有界验证与独立审查

新增 16 个不同案例、233 个断言在五次运行中通过：初始身份 4／62、资源 5／76、野孩子／枪资格首 4／55、自爆 2／29，以及同行发现晚回调漏洞后新增 1／11。最后一个用例只运行新案例，原四例被过滤。有限类型按真实变更根执行；测试故障注入的 this、抛错 getter 类型和检查配置路径首红均保存，后续只修失败根或实际变化范围。

四组职责头首次无诊断；后继仅类型注解与同头的真实逻辑差分分别用完整输出／源码桥承接。四组主证明核完整旧程序与精确政策差分，后继三源窄桥核五个实际消费前守卫和 canShoot getter 后守卫。上述证明明确说明 actual JS 与行为改变，不用逆向恢复旧稿冒充运行等价。

Root 审查全部四组；资源作者独立审安装组与野孩子组，野孩子作者独立审自爆组，自爆作者独立审资源组。审查核实际前态、当前源码、完整原函数、关键调用者、手写预期、中文说明以及各检查的真实源码阶段。首 fence、后继测试输入、首次正式报告与晚修订证据保留，不把不同采样阶段包装为统一复跑。

## 后续范围

本功能不删除 Role.camp，不改变 Camp 当前输入或角色构造器；它先关闭已知的共同失败执行复活问题，为下一批单一当前阵营来源准备边界。全部 55 个专属角色行动、Camp API 退休、全量类型／玩法／复现门禁、全仓中文说明和 P9 零债仍在完整目标内。本批没有模型调用、私配置修改、全量门禁重复或自动推送。
