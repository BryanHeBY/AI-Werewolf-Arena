# 测试 support 按职责收口

58 个原 support 文件拆为 79 个实际 owner，另 18 个已有 owner 保持，共 97 个 TypeScript 模块。数据契约与手写计划归 contracts／builders，真正对局、HTTP、进程、录制与复现执行归 drivers，原字段与动作预期归 oracles。

完整 transport driver 保持原 server、回调、录制、复现、延时和 finally 清理。十段原断言代码移入独立 oracle，未生成新预期、调用生产结算算法或增加通用 cleanup 框架。五族录制支持拆开动作供应、原计划／预期与实际执行；原常量和缓存有唯一 owner。

201 个消费者的 410 个绑定指向原声明的新位置。159 个原声明具有唯一归属，157 个原文保持；两个 driver 按十段实际代码恢复原程序。原数组、矩阵、调用和资源分配保持。赤月的计划函数实际推进生产引擎，因此归 driver；其胜者与存活名单是排演结果，未称作独立字面玩法 oracle。

固定输入的 280 个候选入口类型检查通过，实际模块图 97 个文件／176 条边没有循环。两个 ACP 脚本四处路径迁移与 fixture 清单同批提交，原完整程序和具名声明保持；904 个归档没有改写。局部证据与独立分类／初始化审查见[证据](generated/support-responsibility-evidence.json)，脚本检查见[导入迁移说明](fixture-import-relocations.md)。

暂存使用明确冻结的 support 与消费者快照。并行不透明状态的四个类型适配和后续状态门面的进口变化保留在工作区，分别提交；没有用当前漂移文件冒充本批原程序。七个编译后路径／职责头修正只改变目录、导入及准确说明，原编译输入保留。

本批不宣称完整模块初始化次序相同，也不把旧生产生成预期升级为独立验证。没有重复整局、模型、全量发现或门禁；P2 整阶段及最终同输入验收仍按退出要求核对。
