## 最后收敛的真实边界

- 角色名称由 `game-text.roleName` 唯一拥有；catalog 退出名称镜像。
- 可见性、目标提示、工具校验、夜间阶段、死亡钩子、角色贡献和两层判胜扩展收到实际窄查询与具体命令，通用执行器不再按角色取证明。
- 原世界、组件、资源和请求证明留在实际所有者；公开选枪结果只有数据，复制编号或对象字段不能取得授权。初始化只保留自己的原容器及初始阵营写权。
- 内建完整程序的静态身份登记只登记冷定义，不缓存当局状态；替换方法和外来同名扩展不能继承可信输入。
- Tape3 保留实际已复制的正常返回候选，候选不证明付款或拒绝原因。Noble 三种指定请求故障通过显式离线计划记录与重放原生命替换，不把测试 spy 的未记录副作用冒成可复现因果。

迁移方式、明确退出的 API 和来源指纹影响见[迁移指南](../guides/migration.md)。有限行为修正、首红和后继范围均由各正式验收包保留；不把结构重构等同任意 JavaScript 观察等价。
