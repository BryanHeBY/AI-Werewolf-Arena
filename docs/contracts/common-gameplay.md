# 共同游戏机制

具体角色差异见[规则卡](../rules/README.md)，具名配置变体见[策略 spec](../rules/policy-variants.md)。以下概念不能因模块复用而合并语义。

## 狼队权限

真实身份、阵营、胜利归属、互认、狼聊、狼刀和自爆分别判断。普通狼双向互认，隐狼、石像鬼和机械狼等按本族规则决定是否知队、入聊或继承刀权。队友知识不随未公开死亡消失；聊天和行动仍核当前存活、阶段、生命与资源。

私有狼队事实按发生时的合法受众保存。后续身份或阵营变化不补发旧秘密；玩家序号局部连续，不能用全局事件缺口泄露隐藏行动数量。

### 夜聊与刀票

夜聊每人最多三轮，并非必须说满。`speak_to_wolves` 的 `text` 是发给本轮合法狼聊成员的消息；同一条消息设置 `end_chat=true` 时仍正常送达，随后只退出本人本夜的后续夜聊，不结束其他人的发言。无需等待全员确认后再额外发表一段结束理由。全员退出或达到轮次上限后进入后续阶段；有刀权的玩家仍单独提交 `kill_vote`，夜聊中的目标建议与退出均不提交或锁定刀票。

LLM、Pi、ACP 使用共同的中英提示：夜聊偏向简短接话，已有意见可直接赞同，后续只补充新信息或回应分歧；通常一两句话，复杂布局仍可展开并保留人设，不强制字数或打法。提示展示本轮请求已提供的轮次，不猜测旧请求缺失的信息。生产模型的默认异常回退发送“暂时没有补充”并退出后续夜聊，不假装已达成共识；实际收票和可见性仍由原机制处理。

## 查验结果

`InspectionResult` 区分 `camp`、`role` 和 `combined`，都是规则揭示的标签，不等于真实身份或阵营。具体工具决定允许的类型，模型不能自行要求更多信息。目标的伪装标签不改变实际阵营、刀权或胜利归属。

原生预言家的 `seer_checked` 只揭示阵营且只向本人投影。完整 `result` 优先于兼容 `isWerewolf`；false 不代表一定是好人。旧档确实只有 boolean 时才恢复旧好人／狼人标签；未知或畸形结果保持未知，不猜测也不执行 getter。共享解码、终端与前端消费同一结果标签。

## 女巫与伤害保护

女巫刀口披露取本轮规则允许的基础狼刀，不泄露其他秘密伤害。原生解药与毒药独立计数，空动作不消费；默认本夜至多一瓶原生药。自救、耗尽后的刀口披露和双药实验只由显式配置启用。

狼刀、毒、枪、梦亡、反噬等保留各自来源。基础守卫与解药不消除毒死因，同守同救按板子政策处理；复制守护、梦保护及其他屏障按相应机制独立结算，不套用统一布尔保护。

## 死亡与动作授权

同一波先实际标记全部死亡，再处理合法遗言、警徽、死亡技能和追加死亡，最后到指定检查点判胜。死亡来源阶段与当前阶段分别保留；白天执行的夜来源链仍按夜来源规则判断。

死亡枪、遗言及警徽选择持引擎授予的临时许可，绑定具体请求、演员、生命及来源。字段相同或复制对象不能重建许可；异步返回后及提交前复验当前性。合法空枪与非法目标不同，原生、复制及赠枪各持自己的库存和来源约束。

已提交效果和未付行动窗口具有不同生命周期。后续错误保留实际提交前缀及原错误，不统一回滚；追加死亡不重复遗言或已消费技能。末神或末狼死亡不能提前截断仍须完成的链。

## 自爆窗口

| 窗口                | 阶段   | 时点                                 |
| ------------------- | ------ | ------------------------------------ |
| `on_pre_election`   | Day    | 首日启用警长、无初始警长时的报名之前 |
| `on_daybreak`       | Day    | 夜死与遗言完成后、选择发言方向前     |
| `on_per_speech_gap` | Day    | 每个正常发言之后，包括最后一次发言后 |
| `on_pre_vote`       | Voting | 放逐票请求之前，默认窗口             |

窗口必须同时在 `enabledWindows` 与对应 hook 中启用；显式空列表关闭。竞选前自爆中断当天，不自动在次日补选。首夜待死亡玩家仍按首日流程参加该窗口；自爆与待夜死合并逐人来源，完整处理后才判胜。

选择并发收集，随后复验身份、生命、阶段与工具规则，取仍有效的最小稳定玩家 ID。提交者同步发布事实并进入死亡结算后才等待后续钩子；取消后的旧选择不能产生公共事实。白狼王使用独立带人动作、事件和 `WhiteWolfBlast` 来源，限制见[白狼王规则](../rules/awa-white-wolf-king-v1.md)。

## 公共参与

白痴翻牌免死不属于死亡，之后仍可发言，但失去投票、竞选、继承警徽及再次作为放逐目标的资格。公开流程共享资格查询，不能只在 UI 或目标提示中排除。

选举候选、选民、退水、PK、警徽票重和持徽者选择按板子策略分别处理。没有合法候选或有效票不擅自恢复已退出候选；临时死亡警徽选择不能变成普通存活玩家的随意动作。

## 胜利与展示

真实阵营计数和获胜成员关系分别表达。屠边、屠城、人数条件及第三方目标按板子声明的顺序，在必要死亡链结束后求值并只封盘一次；原始结果与运行中断不是同一种结束。

录制保存稳定原因及成员身份，显示层生成中文或英文标签；玩家原文和机器 ID 不翻译。旧档缺失的成员或原因不由当前阵营推补，未知结果保持原始未知表示。公共读取与严格动作复现的兼容边界见[档案契约](archive-compatibility.md)。
