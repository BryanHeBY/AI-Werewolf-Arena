# 实际阵营、原体与资源写权

## 三种身份语义

Role是现场身份／私有容器，Camp组件是唯一实际阵营，Victory是独立获胜成员关系。Catalog元数据只供默认初值；查验标签、历史队友、已告知知识不冒充现场Camp。Role.camp及旧constructor camp参数已退休，不提供getter fallback、Role→World注册或镜像。

init持同一可写initialCamp与晚currentCamp，bootstrap安装实际draft；默认Victory在实际分支晚读当时Camp，custom membership不因此多做World查询。worldless fixture必须显式给拥有的Camp组件／source，不能通过全局WeakMap偷偷恢复旧输入。

## 原体比较与动作退休

每族保原Role／life／版本／state／policy／Camp ref或值比较。严格OriginalPlayerScope保own-data及组件引用政策；较宽OriginalParticipant不强化成它。普通value-only同值Camp替换仍当前；双ref族同值新组件仍能撤权。

身份转换安装失败由真实writer退休捕获Role对象的执行资格，跨World同对象不复活。不是Camp镜像，也不是所有读取变成授权。目标、纯state／DTO、历史知识和已付predicate不统一过滤；动作入口／最后消费点拒已退休对象。

## 能力与枪的实际写权

`features/night-abilities`完整拥有普通实例字典、metadata、原生安装、grant／transfer提交和晚执行；具体瓶数、梦历史、借用及Demon审计仍归本族。gift／copy／borrow／native／transfer来源不互相冒充。

F03 transfer先原完整预检，再源delete／退休，后目标安装和两个事实。允许异常保留已经删除源或已经安装目标的前缀，不退款或镜像补回；稳定自有库存路径的新接受规则属于明确行为政策，不借迁移扩大成全部grant的schema。

`features/death-actions`的native／learned／gift枪保各自stock捕获和付款。未消费动作可拒退休；已消费pending按原体／来源／生命纯current复验，不因新行动墓碑统一撤回。stock撤权的原错误优先、pass／miss／保护的原付款时点不能重排。

## 纯数据与编码

字段descriptor reader、Projection、宽structuredClone、live schema、JSON编码与严格归档是不同入口。合法getter／Proxy／扩展字段是否接受要看原owner，不能共用一个“更安全”reader收窄全部族。

Fragrant／Demon的live引用和已提交JSON字段各一份；JSON编码失败保已经完成的live写，不把它误称lease／paid账本已提交。普通checkpoint完整容器clone可保扩展字段／别名／cycle；后续JSON／格式拒绝仍在其原时点，不提前过滤为按Role裁剪快照。
