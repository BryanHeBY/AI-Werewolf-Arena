# 具名规则变体与配置边界

AWA 默认规则是自身声明的有限版本，不是某平台全部规则的镜像。官方规则、赛事积分、攻略和工程补全分别说明；外部来源不能自动改变默认行为。

公开板子 `roles` 只接受实际在场角色的参数。未知字段、未知策略、缺少对应角色及不支持的组合均拒绝。策略值包含版本；完整录制携带归一化配置，严格复现还检查源码和锁文件身份。每个参数片段都必须放入合法完整板子。

预言家 `targetPolicy` 默认为 `awa_alive_v1`，允许自验和重复；`awa_fresh_others_v1` 仅允许其他未验活人且不重置历史。`actionPolicy` 默认为 `awa_required_when_legal_v1`，显式 `awa_optional_v1` 才允许跳过。没有合法目标时不产生不可能完成的请求；赛事未验人扣分不被当成通用的目标合法性规则。

## 原生死亡枪与身份查验

猎人与狼王原生死亡枪默认`deathActionPolicy=awa_qualified_sources_v1`：非空复合来源全部属于WolfKill/MechanicalKnife/AwakenedHiddenKnife/Exile/Shot/WhiteWolfBlast才可开枪；含Poison或其它源均否决。空来源与未知来源不猜。候选`awa_knife_or_exile_v1`仅允许前三种刀和Exile，仍要求每一复合来源合格；是有限AWA产品策略，与现有较严格刀/放逐版本概念相符，不宣称主流或完整赛事规则。保留现有毒静默事件、空枪消费、临时死亡授权、晚校验及完整追加波次后判胜。只配置原生猎人/狼王；机械/觉醒复制枪和赠予/转移枪保持自身原有资源、激活、死亡失效与合格来源语义，不从持有者板子参数自动继承。

石像鬼、通灵师、魔镜少女配置`inspectionPolicy`，有限值`awa_unique_required_v1`、`awa_repeat_optional_v1`、`awa_unique_optional_v1`直接复用现有三种目标/行动策略。默认分别为unique-required、repeat-optional、unique-optional。角色身份policy(gargoyle/psychic/mirror)与配置策略分离：原生时序、阵营、伪装标签、继承与石像鬼查后刀资格保持各自机制；切换目标/行动策略不能换阶段或身份。均不可自验/查死者；unique按实例整局history，无隐式重置；无目标不发不可能请求。石像鬼合法skip仍结束本夜原生查验流程后才可出刀，非法或撤权不能授刀。

新copy/gift按显式来源初态，transfer保存实例策略与history，不凭持有者config重写。请求构造前后、await、gateway与提交检查策略身份；未知版本fail closed。实例、validator、目标提示、baseline/ObservedBot、双语规则提示、独立player DTO、内部BoardConfig严格schema、JSON录制与实际Tape复现必须同语义。具体role报告仍尊重已有伪装，不新增真身份穿透。

## 摄梦与狼美人

### 摄梦

[网易 2026 普通能力回顾](https://langrensha.com/news/update/20260402/26905_1294456.html) 此轮抓取仅返回站点壳，保留此前已读的每夜必选、夜伤免疫、仅夜死牵连和连梦致死条款；不以抓取失败结束核对。[官方账号 2017 技能解析](https://www.sohu.com/a/203299808_729113) 此轮可读正文：强制施梦、目标不知情，夜刀/药/枪落空，连梦不可救，摄梦人夜死牵连，梦死猎人/狼王禁技能。该文猎人枪例没有完整定义后续 Day 来源链；本引擎继续用 Night 来源传播，并把这种传播标为 AWA 工程约定。

| roles.dreamer.protectionPolicy | 行为                                                                                                                                                                                                                  |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| awa_night_damage_v1（默认）    | AWA 默认。挡普通刀、毒/合法返回毒、机械/觉醒刀、Night 来源枪/魅惑、奇迹反噬；不挡机械守护失败、黑市反噬；不挡 Dream 死因                                                                                              |
| netease_2026_night_immunity_v1 | 保持强制选择/夜关系/连梦/禁枪；将本引擎初始夜伤中的机械守护失败和黑市反噬也归入免疫。**这两项扩展交互是根据“夜伤免疫”作出的工程补全，原文没有这些角色的逐项矩阵**。连续梦亡和施梦者实际夜死牵连仍使用 Dream，不被免疫 |

策略只改变上述已列夜伤矩阵，不开放任意 bool、自梦、弃梦、白天牵连。其它合法目标为空则没有请求；非法/取消/晚提交不构成合法梦，每夜至多三个离线能力请求尝试，失败沿既有处理。Guard/Heal不救 Dream；复合 Dream 禁枪。保护关系绑定演员/目标生命版本，白天普通死亡无保护/牵连，夜源枪虽在 Day 收集仍沿 Night 根传播。独立梦实例用自己的策略，transfer 保策略、lastTarget/lastDay、计数/本夜使用标记；受赠人原生参数不重写实例。政策变化撤销未提交 scope；已提交夜关系保持提交时政策。

机械狼 profile 的支持组合仍不含摄梦人；来源核对时没有放开该公开组合。机械失败与梦交互仅以低层真实 frame/伤害结算测试覆盖，不能称对应公开板子已验。黑市/摄梦属于已支持组合，已通过实际双语对局与严格 Tape 验证分叉。

### 狼美人

[2017 英雄榜 S7 手册](https://www.sohu.com/a/138501023_729113) 狼美人段规定放逐/猎人枪牵连、毒杀不能发动，禁自刀/自爆/相邻夜同目标。不是 AWA 原来毒牵连的来源。[官方账号 2019 狼美人骑士攻略](https://www.sohu.com/a/323447967_729113) 明示可以空连及骑士决斗封魅惑；没有可读取的完整复合死因表，技能图来源核对时链接 404。因此不推断完整 2019 死因矩阵，也不创建同名全平台 preset。

原生猎人来源由 DeathResolution 本次 resolve 内真实提交的 hunter_shot 记录，生命周期只限本死亡链；不扫描旧公共事件猜来源，不把通用 Shot 自动认作猎人枪。Night 猎人枪牵连可被有效梦保护；白天放逐/枪链无上一夜梦保护。目标 Charm 死因禁尚未执行的死亡枪，追加波次不重复遗言；已提交合法动作不回滚。关系消费前重验来源与绑定的 policy/角色/state/生命，策略改动撤销晚提案。末狼放逐优先仍是 AWA、只作用于真实 exile_settled 的 slaughter_side 条目；S7 来源不证明此额外判胜规则。

**2019 空连与骑士抑制作为已支持的独立约束保留**，S7 参数仅选择死亡触发表；不宣称复刻完整2017赛事。null/无行动消费本夜、清关系并打断相邻限制。自刀限制保持仅本人的刀票，不因队友目标校验泄漏狼美人身份。这也是 AWA 工程边界，S7 原文未定义秘密校验协议。

## 女巫刀口与原生双药

`roles.witch.knifeVisibility`仅支持`awa_with_heal_v1`（默认，解药本夜仍可用才披露刀口）和`awa_always_v1`（显式AWA产品口径，耗尽解药后仍披露），不声明后者是已核验官方主流规则；未加入无来源的第三种隐藏刀口选项。已有`selfHeal`三值与其双语/录制/原生资源语义保持。

`potionPolicy=awa_one_native_v1`保留一夜一原生药默认。`awa_both_native_experimental_v1`明确是**非已核验主流规则的AWA产品实验**：一次有效原生女巫用药后仅开放一个新的单动作回合，最多各一瓶；空动作/无回复/非法动作终止。同夜关闭后不能重入，不重用同一瓶，复制、转移和赠予药不获得该权限或额外刀口。赠毒独立可用不是原生双药来源证据。

策略变化撤销已构造的未提交请求；赠药、复制和转移资源保持自己的来源、库存和激活规则，不从持有者配置继承额外原生权限。

## 警长选举、放逐 PK 与警徽

`mechanisms.sheriff.electionPolicy=awa_nomination_offstage_pk_v1`、`badgePolicy=awa_holder_choice_v1`、`mechanisms.voting.exilePolicy=awa_one_pk_v1`组成有限AWA产品规则。各省略参数保留直接选举/顺位移交/直接放逐默认。PK候选人不重投，最多一次PK，再平票或全弃票无徽/无人放逐；唯一最终警长候选直接授徽，首轮仅从未上警者投票，PK轮退水者可投。警徽选择只能在真实死亡持徽者的引擎临时授权中进行，继任保留票重；非法/无动作撕徽，撤权不提交，白痴翻牌直接撕徽。来源只支持上表描述的部分，命名始终AWA，不冒称官方整套规则。

警徽选择请求禁用 fallback；SDK／ACP 失败、空回复及非法回复不能自动代选继任者。

## 公开死亡与遗言

依据[网易官方2017-10-18规则页](https://langrensha.com/wanfa/guize/2017/10/18/26899_719311.html)：六人明牌局死亡/出局翻身份牌，标准暗牌局不翻；首夜夜死有遗言，所有白天死亡有遗言，时间设置还明确自爆遗言。只引用这些局部条款，不宣称完整网易平台预设。

`mechanisms.disclosure.deathRevealPolicy`：兼容默认`awa_hidden_v1`不新增死亡翻牌；具名`netease_2017_open_v1`在真正结算死亡时公开当前身份牌。只发布`player_role_revealed {playerId, role}`，不披露真实阵营、胜利归属、查验历史、复制/赠予技能或资源。公开的是牌面角色ID，不是查验伪装标签；未结算首夜待死不提前翻牌，白痴首次放逐免死仍走原专属公开事件。每个生命只发布一次，重复处理不重复事件。

`mechanisms.lastWords.policy`：兼容默认`awa_initial_wave_v1`完全保留原首波、死因与日夜限制。`netease_2017_day_and_first_night_v1`允许首夜夜死及全部白天/投票死亡者在各死亡波次遗言，包括自爆、带人和白天枪链；首夜之后夜死无遗言，存活白痴不获遗言。空/未知死因不猜。夜间衍生枪/梦/魅惑死亡沿既有nightOrigin记录视为夜死；日夜混合首波沿既有deathPhases逐人判定。这是工程中日夜分类的明确解释，不更改夜序、伤害、死亡枪资格或完整死亡链后判胜。

参数必须经公开严格schema/default/apply/internal schema/反向转换/双语规则提示/录制/Tape贯通。遗言权限绑定解析时策略及现有生命、阶段、日次授权，请求构造/await/gateway后变化撤权。新事件显式进入玩家公共可见性白名单，wire只保留公开字段；回放共享事实reader验证角色ID、玩家引用和额外字段，坏事实不产生部分标签或状态效果。
