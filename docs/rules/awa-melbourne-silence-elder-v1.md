# 禁言长老：AWA 文字动作与翻译版

<a id="silence_elder"></a>

## 来源与采用范围

核验日期：2026-10-15。角色 ID `silence_elder`，中文禁言长老，英文 Silencing Elder；规则政策 `awa_melbourne_gestures_v1`。本卡先冻结规则，实际启用以配置、运行、完整局与审查通过为准。

第一方依据：[主办方角色图鉴](https://melbournemasters.org/setups/roles/禁言长老)、[禁言长老标准十二人板](https://melbournemasters.org/setups/jin-yan-zhang-lao)。主办方规定夜间选一名禁言对象，限制次日放逐发言中的有声语言，保留动作／手势表达并可指定翻译；夜间流程由长老选择对象和可选翻译。

采用原板身份：四普通狼人、四平民、预言家、女巫、猎人、禁言长老。长老为好人神职，计入神边；按屠边胜负。警长、暗牌出局、遗言、同守同救等共同规则遵守显式 AWA 板参数，不宣称完整复刻线下赛事。

原来源没有裁定文字动作、翻译请求、空过／自选／重选和失败处理。下文将这些作为 AWA 工程补全，不能据角色名扩大到全场禁言或取消票权。

## 角色与夜间行动

- 长老不拥有狼队互认、夜聊或狼刀；查验表现为其真实好人阵营和原身份，无伪装。
- 从首夜起每个实际夜晚选择一名当时存活玩家，可选本人，可连续选择同一人；目标必选，不允许用缺失／null伪造空过。其余字段严格校验，不允许自行填写日次、来源或生效状态。
- 同次行动可指定一名存活翻译，或明确 `translator_id=null`。翻译不能是禁言对象，可为长老本人或任意阵营的其他活人；不会向长老或对象公开翻译的真实身份。
- 工具 `silence {target_id: number, translator_id: number|null}`；实际夜窗、合法名单、最早 deadline 与原长老／目标／翻译生命绑定。晚校验失败、非法目标、迟到／旧回合不提交、不默选目标、不生成有效禁言。
- 本夜已合法提交后不可二次选择，不因后续 Provider／记录异常重新开放。单夜次数只在同步真实提交处消费；不同生命或替换容器不能继承旧请求。
- 长老选择在本板其它夜间主动技能之前完成；狼队独立夜聊流程和刀票照原 AWA 时序，禁言不限制夜聊。不为动作序号或语言新增全局状态。

## 已付效果、公开与到期

选择合法提交形成仅属于本 World／本夜／目标原生命的已付效果。长老之后因狼刀、毒或死亡链出局，不撤销这一夜已经提交的次日效果；长老被换身份亦不让新主体编辑旧效果。未提交的请求仍需原长老实际资格。

禁言对象若在普通白天发言前已真实死亡，则不请求其动作。复活／替换生命不会继承旧禁言；翻译换生命、出局或失去当次发言资格时，不委托其他人、不补译。合法已付选择不以未发生的后续步骤冒充已告知。

首次普通放逐发言前公开禁言对象及可用翻译，不公开长老编号。首日警长选举、当夜身份知识和夜死公告仍按原流程，禁言公告不提前泄露未公布死亡。夜间选择事实仅长老本人可见；效果原体与撤销原因属于 God，不投影给普通玩家。God 全知回放与逐玩家导出分别处理，工作台席位筛选不充当权限过滤。

效果只约束该日放逐讨论及其 PK 发言；警上竞选、退水、遗言、夜聊、工具技能和投票均不受禁言。狼人在普通发言间隙的合法自爆仍可用，不借禁言隐藏其发动事实。首板不支持杠精／定序王子／其他额外发言机制混搭，不能推断它们已完成交互。

实际放逐周期结束或自爆跳过白天后，到期效果关闭；即使没有票、无人放逐或目标当日出局也不顺延。下个实际夜晚开启新选择。完成后不按旧事件反推当前运行许可。

## 文字动作与翻译

受限玩家在自己的普通／PK发言位置收到 `gesture {description:string}`，合法工具不包含普通 `speak`。description 为非空的有限长度文本，用来描述手势、表情或身体动作，提示要求不要写直接口头台词。公开标签明确是“动作”，不会包装成该玩家正常口头发言。

引擎检查工具、长度、原生命、阶段和当前效果，不假装能可靠判断自由文本语义。人格仍可以影响动作风格；动作原文按用户文本保留，不自动翻译或清洗成模型替身发言。错用 speak 需走明确拒绝／纠正，不能普通发言回退绕过限制。

动作已经合法公开之后，若指定翻译仍是原生命且当前可发言，则单独给该翻译一次 `translate_silence {text:string|null}` 请求。翻译只收到已公开动作和其本人正常观察，不获长老身份、未公开夜报或目标私有状态。该请求标识为翻译窗口，不替代翻译自己的正常发言位置。PK 翻译资格不要求翻译自身进入 PK 候选，只要求仍是当次合法存活主体。

翻译通过 `translate_silence {text:null}` 明确不译，非空字符串则发表译文；这是必答的二选一工具窗口。ActionProvider 返回 null、没有合法工具、缺字段或超时都不等于主动不译，不合格回复不编造译文。Provider 真正异常保留已公开动作与原错误，不吞错后制造成功。不无限重试、不重发动作、不付第二次夜间选择。翻译文字明确署名，由翻译本人承担，可以误译或带有自身立场，引擎不认证其内容为事实。

普通动作及翻译的请求各有独立 RequestLease／RequestDelivery；最早 deadline 限制实际交付。已公开动作、已完成表达与尚未开始翻译分别记录，关闭不统一回滚先前成功前缀。原长老／目标／翻译的替换或晚撤权不能消费新主体库存。

表达没有额外库存：真实手势或翻译事实发表成功，且对应窗口处理落定后，才发送该请求的 `true` 完成通知。发表或通知异常保留已存在的事实前缀和原错误，未完成请求关闭为 `false`；不重开同一表达轮次，也不把后续译者失败追溯为前一手势失败。夜间选择另以历史槽的实际替换为付款点，二者不共用完成时点。

## 配置与有限组合

只开放具名 `policy: awa_melbourne_gestures_v1`，不添加没有可靠分歧依据的“禁止投票／警长／遗言”“永久禁言”等开关。目标必选、自选可用、可连续重选、翻译可选及仅当日有效是该 AWA 版本的公开固定条款。

首批仅上述来源十二人结构，每角色数量、神边／民边、屠边、夜序和发言机制由完整 schema 与 ruleset 同时核对。不开放多长老、技能复制／赠予／吞噬、号码映射、典狱交易或其他特殊表达组合。未来有来源再增加独立具名策略与交互验收。

公开 board 与中文／英文 game 一起交付，引用示例现有 Agent，给出预检和运行命令；不读取或覆写私人 runtime 与认证。

## 验收与人工预期

1. 首夜禁言本人／其他活人、带翻译／null翻译；第二夜重复同目标；公开普通动作及独立翻译后，正常票权、候选资格和警徽不变。
2. 首日选举可正常 speak，夜死公告后才公开存活对象；普通／PK发言只允许 gesture，遗言和狼聊仍按原工具。
3. 长老当夜已付后死亡，次日效果继续；对象夜死不请求；目标重活不继承；翻译死亡不补译；自爆跳白天不顺延。
4. 错目标、非整数、缺 translator 字段、目标等于翻译、同夜重复、旧 request／跨 World／替换组件、最后 getter 后撤权均拒绝或按明确失效路径关闭。
5. 正常翻译、明确不译、Provider异常、动作发布后记录失败、翻译迟到及强制回收保留各自真实前缀，不能重放已完成动作或冒充完整成功。
6. God／长老／对象／翻译／无关玩家字段矩阵、局部可见序号、中英提示／工具／错误／自然语言终端和 Web／视频、原用户文本保持。
7. 真实 bootstrap 的完整双语脚本局、受限观察自然局、SDK HTTP/SSE／ACP-MCP／mixed本地通路与失败局、独立审计和严格 Tape、原普通板回归。

具体落点为 `features/silence-elder` 的唯一状态／夜窗／表达窗口，rulesets 具名组合接入普通及 PK 发言。共同流水线不按角色 ID 重写规则；共享事实与展示由契约／展示包拥有。未达到上述门槛前不注册为可运行角色。

## 示例与回归边界

原十二人入口和两语 God 教学见[禁言长老示例](../examples/silence-elder/README.md)。状态只记录本人已付历史，夜窗与表达权由本族原生命所有者持有；普通与 PK 发言通过表达贡献接入，不向阶段管理器追加逐角色分支。

回归覆盖自选／重选、译者选择、租约、死亡／换体、公开顺序、失败前缀和独立审计。普通／PK 译者不要求候选身份，未提交不能冒充主动拒译；失败表达后的已发表动作和未发表夜间付款均保留真实前缀。

God 事实自身不改变生命、身份或票权，中文／英文帧及倒看分别验证。公开教学回放不携运行授权，不代表严格 Tape 可跨构建执行；高级混板和额外表达机制仍不开放。
