## 可核来源与有限原板

[赛事主办方 Melbourne Masters 角色页](https://melbournemasters.org/setups/roles/典狱长)和[孤注一掷标准版](https://melbournemasters.org/setups/gu-zhu-yi-zhi)均说明：狼人角色，次夜起选择两人秘密交易；双方只知道对方座位而不知道身份，分别选择交易／背叛；双交易免夜间伤害，双背叛成为当夜技能目标，单背叛则交易者出局；选本人时相同选择使典狱长出局、不同使另一人出局。两处正文没有进一步定义“当夜技能目标”，原板流程摘要也没有完整展开此分支。

原十二人牌池是典狱长、3 普通狼、4 平民、预言家、女巫、猎人、摄梦人。初版仅此精确原板；其它同名平台和社区魔女会变体不得混用。来源没有明确互认、刀权、自爆、每人可参与次数、强制目标、精确保护和已付失败。以下所有冻结细则均标 **AWA 工程补全**。

## 双背叛证据边界与已裁定解释

这不是可把任意解释混装的配置开关。公开主办方正文及原板正文只有同一摘要；已读公开页面数据未找到可补全语义的独立细则。下表保留考察过的解释，**本版本仅采用 C**，不冒充完整官方规则。

| 候选解释                                                | 对原板真实影响                                                                         | 当前缺口                                                                         |
| ------------------------------------------------------- | -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| A：双方各自的主动单目标夜技能强制指向对方               | 预言家验对方、女巫毒／救须面对刀口资格、摄梦人改梦对方；普通狼个人票不等于狼队共同刀口 | 必须定义可选药种／库存不足、毒救不同目标域、狼队集体刀权、已选历史与禁重复的冲突 |
| B：双方遭到的夜间目标相互交换                           | 所有人验／毒／刀／梦指向 A 的映射到 B，反向同理；本人的选择未被强制                    | 来源未出现“交换”字样；与 A 有本质差别，不能借已有交换机制偷偷实现                |
| C：双方只互为各自可用技能的强制目标，共同狼刀另具名处理 | 与 A 相似但明确区分角色原生行为和团队行为；平民／猎人无主动夜技能则不凭空造行为        | 仍需明确普通狼／典狱长与狼队刀票、女巫救人、摄梦人连续对象及目标死亡的终局政策   |

**AWA 具名补全 `awa_warden_partner_native_v1`**：双方各自原生、主动、单目标夜技能必须选择交易对方；集体狼刀与每人的刀票均保持原规则，不强制为另一参与者。没有原生主动夜技能的平民、猎人、普通狼和典狱长不新增行为。该效果不交换外来目标，不改变其他人的选择。

- 预言家仅能查验 partner，报告仍来自真实预言家能力。
- 女巫 `none` 可随时明确空过；heal 仍要求有解药、原自救政策允许且 partner 恰为真实原刀口。否则不能救 partner，可选 none 或满足原库存／原合法目标规则的毒药；不默默耗药或制造救人成功。poison 只能指向合法 partner。
- 摄梦人仅能选择 partner，必须用 partner 的真实连续历史结算；连续同对象导致死亡不能用“强制”清空历史。若 partner 已失效或原规则无合法动作，显式失败并撤销未付交付，不生成替代目标。

## 可先确定的状态机边界

1. 真 Wolf、胜负沿狼队与本板屠边侧。**AWA 补全**：与三普通狼双向互认、狼聊与群刀，可自爆／自刀，互认仅座位。
2. N1 不请求交易。N2 起每夜一次 `warden_pair {target_ids:[number,number]|null}`；两人不同且当前原活，可含典狱长自己；null 空过零消耗。**AWA 补全**：每名玩家整局最多参与一次（含典狱长自己）；合法 pair 在原体及双方候选复验后一次记录参与资格付款，不等决定收齐才扣。少于两名未参与的存活玩家时不生成 pair，允许明确 null。已付 pair 后任一决定失败，参与资格与已收决定前缀保留，不重选／不恢复库存。
3. 选择成功后只给两参与者彼此座位及本次可选值，不给角色／阵营；不公开典狱长座位，自己入局时另一人也只知道交易对象座位。分别 `warden_decide {choice:"trade"|"betray"}`，彼此决定、选择顺序和是否完成不可相互泄露。典狱长不因主持而获得两人秘密选择；God 可保全因果。
4. 必须先冻结两人的原体与本次会话，再等待双方；合法 action accepted 不是效果付款。双方缺失、非法、超时、换体或租约撤销都按明确失败保存，不默认判交易／背叛，不补造正常结束；若一人已付款，其事实与资源前缀不回滚。

## 已冻结的 AWA 交互与实施约束

- 双交易保护独立于守救抵消，只免当夜普通刀、毒、梦连续／初始与夜源梦殉情；不免交易死亡、不免黎明及后续 Shot。夜源本身保留到既有完整死亡链结束后到期，不提前在天亮字段变化时失效，也不延长至下一夜。
- 单方背叛／本人博弈采用独立 `Deal` 死因，不冒充刀口；纯 Deal 不授猎枪，与刀毒合并时保全真实原因并按共同枪政策检查。原目标只真死一次，词／徽／死后动作保持现有 `lastWordsPolicy` 和有序结算。守护、解药、双交易保护不抵挡 Deal；已付博弈不因典狱长首次死亡回滚，但原体替换／复活不迁移效果。
- **AWA 工程时序**：N2 pair 与双决定在所有个人技能前完成（priority100），保留摄梦150、狼聊200、团刀400及其余原生个人阶段的原顺序；不为本板全局重排摄梦或狼聊；后者均通过已付同夜原生命绑定查询，不从事件文本重建授权。两参与者决定只有各自知道，结算只收到本人与必要目标规则；不得提前向一方暴露另一方已选值或完成状态。
- 每个 await／外部回调后及首语义写前复验原 owner／life／phase／source；已付效果不可用耗空库存再次撤权，目标新 life 不继承旧伤害／保护。
- DeathResolution 保实际死亡波次、该波遗言再警徽再钩子与追加波；PhaseManager 最后判胜。典狱长不能自行写阶段或提前封盘。

## 架构、知情与验收要求

唯一交易状态／参与者／窗口／效果归 `features/warden/`；rulesets 持原板闭包和相对顺序，不能回到中央按角色 switch。公共 game-contract 放无句柄事实，game-presentation／game-text 提供中英文；观察仅各玩家当时实际知情字段，God 完整记录与玩家档明确分开。checkpoint 与独立 verifier 分离，后二者不得读取生产交易结果作 oracle。

必须交付原十二人 board／game 两语入口，SDK／ACP／mixed 的真实秘密双人行动、严格 Tape、20–50 受限 seed、四格普通表＋四格本人表和每种伤害／词徽／撤权手写反例。R 优先核双背叛与自选，A 核原体／时点，T 核双方未完成／部分付款／保密，L+D 核双语／前端帧和可运行示例。本族实现、两路非作者独审与下列验收已闭合，登记 implemented 仅指本卡有限十二人范围。

## 独立手写补全预期

1. A=预言家、B=女巫双背叛；原刀口 C≠A。预言家只能验 B；女巫 heal 不可选，解药仍在，可明确 none 或有毒时毒 A；狼刀票仍可指 C。
2. A=摄梦人、B=普通狼双背叛且上夜 A 已梦 B：A 再梦 B 按原连续梦导致 B 的梦死提案；B 的集体刀票不被强制为 A。
3. A／B 双交易，A 同夜中刀和毒、B 因梦连续或夜源梦殉情：两人相关夜间伤害均被此保护阻止；黎明猎人射 A 仍实际死亡。
4. A trade、B betray：仅 A 获 Deal 提案；猎人为 A 时不获得纯 Deal 枪权。若 A 同时有真实刀／毒，保留完整原因并按原共同枪表决定，不伪造刀或忽略毒。
5. W 与 A 的四格严格为：trade/trade→W，betray/betray→W，trade/betray→A，betray/trade→A；每格仅 Deal，不叠普通保护／强制。
6. N2 pair 已付，A 有合法决定后 B 超时：保留两人已参与与 A 的已收记录，未收 B 不补默认决定，不发表正常博弈结算；下夜不能用 A／B 重新参与。
