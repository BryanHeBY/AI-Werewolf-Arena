# AWA 狼术师有序座位映射规则契约

状态：implemented；公开预设 awa_wolf_sorcerer_12_v1，功能证据见 [本批验收](../expansion/reviews/p9-wolf-sorcerer.md)。支持有限公开板：三普通狼、狼术师、四村民、通灵师、女巫、猎人、魔术师，十二人屠边。狼术师 wolf_sorcerer 与已实现狼巫 wolf_witch 不同。

## 来源和版本边界

Melbourne Masters 的 [角色页](https://melbournemasters.org/setups/roles/狼术师) 和 [魔幻对决板型页](https://melbournemasters.org/setups/mo-huan-dui-jue) 描述魔术师先换位、狼术师后换位再参与狼队。详细首夜流程中两者不交换，狼术师闭眼示意；后续夜晚才依次行动。因此默认首次交换夜为 2，首夜狼术师不获知队友或参加狼队行动。

公开资料对同名角色在其他板子中的顺序描述有差异，例如魔幻赏金含刀后换位和额外赏金机制。本有限板不混入该整板规则，不以本实现声称支持所有同名版本。

## 有序映射

保持实体 ID、角色、阵营及公开座位稳定，仅解释夜间目标号码对应的实际承受者。若魔术师的座位置换为 M，随后狼术师为 W，最终号码到原始玩家的映射为 M(W(number))。这是先移动座位占用者再移动一次的结果。

例如魔术师交换 1、2，狼术师交换 2、3，最终目标 1、2、3 分别作用于原始玩家 2、3、1。交换次序反过来结果不同。同对两次交换恢复恒等效果，但两角色各自消费的号码均不退款；不同且重叠的配对不可错误地独立只换一次。

## 明示 AWA 政策

政策 awa_wolf_sorcerer_seats_v1。号码资源分别归两名施法者所有，每个号码每人整局至多消费一次；可选择自己，仅选择当时存活的原始号码。配对规范化，主动空过不消费号码且不受诡术师的连续空过限制。不足两枚合法号码记录 exhaustion，不制造不可能完成的必需动作。

提供 firstNight 为 1 或 2 的显式 AWA 配置；默认 2 来自上述具体夜序，1 是明确标记的本地特化，并非声称资料一致支持。魔术师与狼术师在本有限板使用相同起始夜，避免混入未验异步版本。
每次轮到可行动角色均要求明确提交合法选择或空过；无效、缺失或晚到动作失败且不消费。成功提交后不因施法者普通死亡撤销本夜效果。禁止复活、能力复制/转移、第三方、恋人及未验混合板。

狼刀、女巫解药/毒药、通灵师具体身份查验共享最终目标映射。查验展示仍使用请求号码，结果来自实际落点。夜死枪口沿用明确 original/exchanged 政策，白天投票和枪口不受本夜映射延伸影响。目标与生命版本、两层映射版本都必须在异步提交前后核验。

## 工程门禁

纯映射穷举必须与独立的座位占用者交换模型一致，覆盖相同、重叠、分离与空交换。之后再接双重夜帧、严格输入、私有观测、精确板型、Tape 审计/重放/篡改拒绝、双语 World、SDK/ACP 和前端回放。
本有限范围已登记 implemented；P9c 阶段全量、P10 和用户总体验收仍开放，不据本批结果宣称所有混合板受支持。

## 狼队知识与逐夜资格

首次合法配对或明确空过提交后，永久保留对原始狼队身份的双向互认，历史队友死亡不擦除已知身份。本夜夜聊与刀权仍须等待本夜交换阶段完成，不能把临时行动资格复位解释为遗忘队友。
