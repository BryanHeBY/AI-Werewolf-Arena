# 杠精：赛事条款与AWA发言窗口改编

## debater

来源：[Melbourne Masters 2026角色图鉴](https://melbournemasters.org/setups/roles/%E6%9D%A0%E7%B2%BE)、[组织者争锋相杠标准版](https://melbournemasters.org/setups/zheng-feng-xiang-gang)。组织者给出一次翻牌挑战、3分钟辩论、全员匿名表决；过半成功使对方停止本轮发言并失去本轮投票，挑战警长成功则接徽；平票或不足半数则挑战者失去本轮票权。该来源是特定赛事公开规则，不能称网易官方或所有平台统一规则。核验日2026-10-09。

唯一首批策略 `awa_melbourne_2026_speech_gap_v1`。离散AI请求不能在一条正在生成的发言中断，也不伪造真实3分钟计时：改为每名常规放逐发言者之前提供一次可选挑战窗口，挑战目标只能是当前待发言者；合法翻牌后挑战者与目标各一次公开辩论发言，再匿名表决。挑战者先发言、目标后发言。非法/未返回发言不合成文字，随后仍表决；请求或provider抛错保留原异常并关闭窗口，已接受的库存/公开事实保留，结果/票权/警徽不提交。两个AI发言和窗口位置是明确AWA改编，不是来源额外规则。不能用任意计时/人次/多数阈值配置制造其它版本。

## 身份、次数与板子

- 好人神职，最多一名；查验标签Good/真实Debater，既有屠城/屠边/狼达半数的AWA计数不变。新角色不获得狼队信息、刀权、自爆或死亡能力。上述胜利条件是既有AWA条件，不宣称复制赛事全板。
- 整局一次有效挑战。未选/非法/接收前传输失败/提交前撤权不消费，之后窗口/日次还可选择；合法接受并公开翻牌/开杠即消费一次；表决未过半或平票也已消费，不补库存。后续流程撤权不回滚合法付费：不再施加结果、票权或警徽效果；阶段已经关闭则不追加事件，阶段仍有效时发布无秘密的取消事实，目标恢复正常待发言流程，保留已公开翻牌/合法辩论。这是工程取消约定。
- 选择actor ID、原生命/角色/privateState/库存/政策、目标原生命/角色/privateState和两人的徽组件/字段，构造请求之后和提交之前均复验。窗口拥有世界内临时token，旧请求/重入/其它phase不能伪造合法动作；已接受的玩家整局提交栅栏防止换状态、复活或重新进流水线补库存。
- 首批支持Wolf/Villager/Seer/Witch/Hunter/Guard/Idiot/WolfKing/WhiteWolfKing/Knight/Debater。未冻结Cupid、Fox、商人、复制或复活板子组合继续拒绝；不能借注册名宣称组合已完成。12人赛事构成为Debater/Seer/Witch/Hunter、4Wolf、4Villager；实际夜序、遗言和其它参数仍按显式AWA板子。

## 表决与权限

- 开杠时冻结所有实际存活玩家，包含双方和已翻牌白痴；来源“全员”在引擎中解释为该时点活人，死亡观众不投票。这一活人范围是工程明确化，匿名开杠表决与普通放逐票权分开。
- 一人一票，警长没有加权，支持数严格大于冻结人数一半才成功。每人提交true/false/null（显式弃权）；非法、未返回、原生命/身份失效计弃权，不减少分母、不猜支持。来源未说明弃票和临时失效，固定分母/弃权是工程补全。任一方失效则整次结果撤销，而非用剩余选民抢先赢。
- God专属debate_ballots_recorded事实、实际决策与Tape保留演员和选票；公共事件仅给支持/反对/弃权总数、固定人数、成功与失去票权ID，不含选票与投票人配对。所有冻结选民收集结束才发布总数，后续选民看不到收集中间总数或其它个人选票。双语显示不能改变匿名矩阵、ID或结果。
- 成功：当前目标不再获得本轮常规发言请求，失去该日常规放逐及其一次PK投票权；若其为警长，使用既有警徽机制自动移交给仍有资格的挑战者，保留配置票重/后续移交政策。失败/平票：目标正常发言，挑战者失去同一放逐轮及PK票权；挑战者原警徽不因此失效。
- 禁票绑定原生命与日次，换角色不洗白；复活/换生命不继承旧处罚，下一日不再阻止投票。不会把永久canVote设为false或恢复白痴原本没有的票权；竞选/警长票不受此放逐处罚。PK发言不是本策略新的挑战窗口，也不因本次常规发言中止而禁PK发言。
- 初始发言顺序按既有警长方向冻结。挑战接徽不重排已冻结名单；被中止的发言之后仍运行原有自爆/骑士间隙。骑士/自爆随后结束白天时，本轮禁票不延长到次日。这是必要组合的工程顺序。

## 录制与人工判例

状态、政策、接受选择、公开翻牌/开始/两段发言/匿名汇总、日次生命禁票与警徽事实贯通schema→实例→提交/晚校验→玩家DTO/提示→God录制→严格Tape→前端/终端/共享视频事实。普通死亡明牌策略保持独立，活人翻牌使用专属debater_revealed事件。

| 6活人4支持/2反对                               | 成功，目标本轮无常规发言/放逐或PK票  |

| 已翻白痴参加辩论表决                           | 匿名表决仍一票，普通放逐仍无票       |
| 成功挑战配置警长                               | 接徽及正确权重；不重排已冻结发言名单 |
| 非当前目标/自己/重复/死目标/角色政策变更晚提交 | 无接受、翻牌或消费                   |
