# AWA 定序王子有限规则契约

状态：implemented；覆盖 awa_order_prince_12_v1 原生十二人板及下文已交付的有限联合板，功能证据见 [本批验收](../history/expansion/reviews/p9-order-prince.md)。P9c 同源阶段门禁已在当时冻结输入上完成，见[历史阶段验收](../history/expansion/reviews/p9c-stage-acceptance.md)；不表示当前重构源码全量通过，其余未验组合、P9 剩余／P10 与用户总体验收继续。

政策 ID：awa_order_prince_first_ballot_v1。角色为好人神职。原生固定身份；不把重投实现为回滚整个 World。

## 来源与口径

- https://blog.huya.com/news/24183 （2020-11-04，《狼人杀官方》联动活动资讯）：每天第一次放逐投票结束可翻牌重投，重投前本人额外发言，一局一次。
- https://bkso.baidu.com/item/定序王子/55603582 ：交叉佐证第一轮而非平票后的第二轮；技能发言期间禁止自爆，警长无需移交警徽。百科不是网易第一手法典。
- https://melbournemasters.org/setups/roles/定序王子 ：社区常见板补充，后续与诡术师/魔术师共同进入诡术之境。

## 明确边界

原放逐票统计完、任何放逐死亡/遗言/警徽移交/胜负封盘之前，向仍存活且未用技能的原生王子提供一次必需选择。被原票指向的王子仍有资格自救。
只在当天第一轮原始投票后提供；不在 PK 轮或已经重投的投票后递归触发。首轮平票或全体弃票也开放选择，这是 AWA 对“第一次投票结束”的明确边界解释，不宣称官方单独说明。尚未找到可信的大众差异依据，不添加猜测性的 tieActivation 配置；未来有来源再新增命名政策。
发动立即消费一次资源并公开翻牌；额外发言后重新收集所有当前合法选民的票，重新计算警徽权重和目标。旧票只作已作废审计证据，不触发死亡效果；新的平票按现有板子 PK 政策，不能再触发技能。
额外发言期间不开放任何自爆窗口。发动未死亡不移交警徽。显式不发动不耗技能；缺失、超时、非法或过期回应抛错，不能降级不发动。
确认发动后若发言/重投失败，保留已消费与翻牌的失败前缀；不回补库存、不把半轮记成完成。
稳定玩家 ID、票面目标、最终放逐对象保持分离；诡术之境组合中的诡术师在最终有效放逐结果映射，不能把旧票误当死亡或提前触发映射。

## 实现与证据

通过既有 VotingPipeline/DeathResolution/ActionProvider；原生主体与生命版本在 await 前后校验。所有 prompt/event/error 文案集中 game-text。
提供独立公开预设 awa_order_prince_12_v1（四狼、四民、预言家、女巫、猎人、定序王子）。另支持 [诡术之境有限组合](awa-trickster-exile-v1.md) 的 awa_trickster_12_v1；另支持 [永序之轮有限组合](awa-time-consort-reflection-v1.md) 的 awa_time_consort_12_v1。原生板强制精确十二人牌组、屠边和一次 PK，通用警长／钩子选项仍可配置；联合板各自保持严格具名预设。配置预检和 bootstrap 共用最终资格检查，拒绝同一种未支持组合。
需要原票救己/救他、弃用、首轮平票、PK不触发、禁止重入、警徽票权、晚到选民/目标失效、缺失/超时、确认后失败库存、双语SDK/ACP/失败Tape和真实UI证据。
