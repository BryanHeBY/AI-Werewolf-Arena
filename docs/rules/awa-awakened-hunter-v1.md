# AWA 觉醒猎人 1.0.0 规则

<a id="awakened_hunter"></a>

角色 `awakened_hunter`／Awakened Hunter；固定政策 `awa_directional_patrol_v1`，核验 2026-10-15。**仅原十／十二人暗夜星辰已完成本角色运行、独立审计与两语交付。另一个原觉醒骑士十二人板不含觉醒猎人，不从别族的全天盾／决斗交付开放巡猎混搭。**

## 第一方证据和范围

[狼人杀官方教学 BV138y6YDEjx](https://www.bilibili.com/video/BV138y6YDEjx/)（2024-10-24，官方账号 mid198427927）[公开规则帧](https://bimp.hdslb.com/videoshotpvhdboss/26442074633_qk7kbb-0001.jpg)55–70 秒说明：好人神职，出局后选择正／逆序，使该方向最近狼人出局；夜间出局时，白天巡猎可无视特殊狼人技能；75 秒以毒药图专门说明毒死仍能巡猎。这里是实际读取官方帧，不能拿剧情预告《无终追猎》标题代替规则证据。

[2025 官方赛事](https://langrensha.com/20250902/31012_1257316.html)提供原十二人暗夜星辰：3 普通狼、觉醒狼美人、4 平民、预言家、女巫、守卫、觉醒猎人；同官方视频80秒提供十人：2 普通狼、觉醒狼美人、3 平民、预言家、女巫、守卫、觉醒猎人。初版只这两份精确牌池；无复制、赠予、复活、座位映射、第三方或其它特殊狼人联合。其它未明的方向、空过、死亡根来源、保护与失败是下述 **AWA 补全**。

## 身份、资源与方向

1. 真 Good／god，沿本板好人胜负及屠边侧，无狼队信息／夜聊／刀；查验真实身份，原生至多一。普通 Hunter 的毒禁枪不适用于本角色，不偷加普通 shoot 工具。
2. 初始一个巡猎单位；真实死亡后开启 `patrol {direction:"clockwise"|"counter_clockwise"|null}`。null 为明确放弃，消费唯一单位；非法／missing／late／未授权不消费，也不能由模型填 `target_id` 选择任意狼。
3. **AWA 补全**：顺序按本局冻结实际座位环，clockwise 为座位顺序前进、counter_clockwise 反向，越界回绕。从本人原座位的下一位开始，跳过已经真实死亡者，取第一个当前原活、真实 Camp.Wolf 的玩家；不按角色显示／查验伪装／AI判断选狼。两方向都允许，即使只剩一狼命中同人；不在 schema 或拒绝文案泄露沿途真实阵营。
4. 原体死亡不会撤销其死亡许可；原 role／能力源／私库被替换则旧许可关闭。每次 await 和最终付款前复验原死亡授权、当前目标原 life 及源根；不能把死后动作都用 alive=true 判失效，也不能复活新 body 后沿旧许可扣其库存。N1 真实无请求阶段固定原生命及完整座位环；之后观察到目标原体／身份失配即永久跳过该原范围，恢复旧组件不恢复资格。

## 来源、特殊能力与波次

5. 官方明确毒死可用。**AWA 补全**：本卡支持板内的刀、Poison、真实放逐及 `AwakenedBeautyReplacement` 死亡都授一次巡猎，复合来源不因含 Poison 而禁用。无任何活狼时关闭且不请求、不伪造目标；仍由 PM 正式结束对局，角色不自发 game_over。
6. 巡猎产生独立 `AwakenedPatrol` 来源和本次 target life。Night 根（含夜里实际毒死）在黎明虽显示 Day 动作窗口，仍携“本次禁用目标特殊狼死亡能力／替死”的属性；实际对觉醒狼美人命中时不触发替死。Day 放逐或日间替死根不携此属性，可以被其一次替死替换。**AWA 补全**：只抑制这次巡猎的目标能力，不永久改角色状态、不撤先前已经付费的其它玩家能力；未支持狼种不推断已验收。
7. 普通守卫／解药不挡巡猎，原十／十二暗夜没有 Dreamer。不得据“无视特殊狼人”推导无视任何好人保护；以后开放觉醒守卫、梦或其它护盾必须另有政策、闭包及三方测试，不在本次首批任意混搭。
8. 先真实标死巡猎者、处理该波词／徽，再在死亡许可下选择方向及同步消费，DR提交目标实际死亡及追加连锁；完整链后PM判胜。第一波末神／末民和最后狼的交互不能提前截断巡猎。目标若已被独立真实死亡或换 life，重新选择目标是否允许取决于最后读点：**AWA补全**规定付款前从实时座位重算一次；付款后固定原目标life，不为晚死亡自动补巡第二人。
9. 遗言明确 `awa_initial_wave_v1`：首夜初始夜死可获一次、N2+夜死无词、真实初批放逐有词、巡猎追加死者无额外词；警徽只随真实死亡处理一次。巡猎遇到替死只按实际死者移徽，保活狼美人不移徽。

## 信息、失败及架构

10. 本人只知原允许方向和自身次数，不提前得计算命中位置；实际成功公开巡猎者及实际命中座位，不把沿途阵营、目标具体狼牌／库存加入公开事实。替死／失效按已确认公共结果展示；God另保source/root/原目标。失败撤权不公开狼位置。
11. 方向选择付款后观察／落盘异常保消费与已提交前缀；若真实死亡已经提交不回滚、不发第二份巡猎。未实际提交不能只凭“选到了狼”更新Web Alive。正常／失败严格Tape要区分选择、消费、提案、替换与真实死亡。
12. 唯一方向巡猎资源与窗口归 `features/awakened-hunter/`；只复用死亡动作的真实请求／授权／提交端口，不复制普通 Hunter 禁枪策略。rulesets持有限组合／死因／抑制贡献；engine持唯一次序／Alive／判胜；不加逐Role中央逻辑。公共DTO、共享中英展示和独立verifier各归既有包／目录。
13. `roles.awakened_hunter` 初版只接受 `{}`；中文“正序／逆序”的提示必须同时列清稳定座位顺序，与英文 clockwise／counter_clockwise对应，不让终端与Web左右镜像倒置。角色、工具、放弃、拒绝、可见反馈和审计两语全贯通，原话不翻译。

## 工程边界补充

`patrol` 使用独立真实死亡许可，不复用 `shoot` 或普通 Hunter 弹药；租约中只列完整原座位环与方向，不含隐藏狼候选。付款成功后关闭请求不撤销已付内存提案，Night 根抑制权仅随真实不透明提案传递，复制 JSON 或手写 `AwakenedPatrol` 原因没有此权限。请求缺失／迟到／异常／末字段 getter 撤权关闭 false 且零新付款；付款后日志失败关闭 true 并保库存，未真实提交不补公开命中或死亡。示例见 [暗夜星辰](../examples/awakened-dark-stars/README.md)。
