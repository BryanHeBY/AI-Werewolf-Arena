# P9b 恶夜骑士：夜间免疫与一次反伤契约

## 首批有限板

仅原生十二人 3 普狼、1 恶夜骑士、4 平民、预言家、女巫、猎人、守卫各 1，屠边。拒绝身份复制、赠予、恋人、变身、商人、其它高级角色和事件包。恶夜骑士属于 wolf，与狼队互认并参与夜聊和共同投刀；禁止其自身自爆，也禁止所有狼刀选择它（不只是本人不能自刀）。

公共配置必须明确选定夜序、女巫自救、同守同救、警长、放逐、遗言与枪窗口。复用已经有证据的基础策略；不默许任意混搭。

首批四份预设固定 awa_initial_wave_v1 遗言政策：纯反伤死亡不授予首夜遗言；同时有狼刀等合资格来源时仍按既有来源集合判断。该项是显式 AWA 有限选择，不宣称所有网易或线下面杀一致。

## 能力语义

1. 夜间狼刀、毒药不能使恶夜骑士死亡；毒药仍消耗女巫本次合法用药资源。
2. 一次反伤是整局资源。首次合法预言家查验或女巫毒药提交可以触发；守护、治疗、无效动作、缺失响应、显式跳过不触发。
3. 同夜验毒只有按实际规则阶段先完成的有效触发消费反伤资源。阶段先后必须出现在板子说明中；不得以并发响应完成速度、实体遍历顺序或随机顺序决定。首批沿用 AWA 的串行基础阶段顺序，不宣称与所有线下面杀夜序相同。具体为女巫阶段 priority 500 先于预言家阶段 priority 600；同夜两者均有效时由毒药先消耗反伤资源。
4. 查验仍给出真实狼阵营，反伤只在统一夜间结算时杀死施法者；不能因为施法者已有待结算狼刀或毒药而提前取消其合法行动。
5. 反伤是独立有来源的伤害，不伪装成女巫毒药或狼刀，不被守卫或解药抵消。与其它伤害并存时保留所有来源。
6. 反伤用尽后仍保留夜间免疫，不能把一次反伤库存和持续免疫绑成同一个开关。

## 枪窗口差异

有限枚举为：

- night_shot_immune：夜间死亡连锁中的枪仍受免疫限制；白天放逐引发的枪可杀死恶夜骑士。
- hunter_shot_bypasses：猎人枪不受该夜间免疫影响，包括夜间结算链。

这两项是对来源差异的显式 AWA 策略，不使用笼统“平台通用默认”。默认选 night_shot_immune，另一项供猎枪例外口径使用。实现必须依据死亡行动的来源/结算窗口，不能仅凭当前 Phase 字段推断天亮枪等同白天。猎人的开枪资格仍由自己的死因政策控制。

## 生命周期与失败边界

请求与提交均核对原角色、能力实例、生命版本及合法目标。晚失效只撤销未结算效果，不篡改已经合法获得的查验历史；是否退还已消费资源必须固定为不退还，避免重入刷技能。失效的毒药目标和非法狼刀不得制造反伤或消耗一次资源。

所有有效伤害与死亡连锁结束后再公布死亡和判断胜负。错误或缺失必需响应严格失败并保留可回放的 partial Tape，不随机代选。
