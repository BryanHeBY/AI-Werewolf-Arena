# 乌鸦：秘密诅咒与次日放逐附加票

状态：implemented；仅限本卡列出的原生十二人板，不支持任意混搭。

## 来源与明确边界

- 网易狼人杀官方角色卡数据：[kapaiData_02806e2.js](https://langrensha.res.netease.com/pc/gw/20190509150909/js/kapaiData_02806e2.js)，角色“乌鸦”，卡号 18。核验日期：2026-10-15。官方说明可证：每晚秘密选择一名玩家，下一白天放逐额外计一票；不能连续两晚诅咒同一人。该卡归好人分类；本有限板将乌鸦作为神职计入屠边，卡类数字本身不证明神民分类。
- 本卡采用官方的 **额外一票**，不是米勒山谷 Scandalmonger 的两票版本。官方简卡没有给出 PK、弃权、自选、死亡后持续等完整裁判细则；以下具名 AWA 选择明确这些边界，不将它们称为网易全平台规则。

## 有限板与配置

首批仅十二人：4 普狼、4 平民、预言家、女巫、猎人、乌鸦各一，屠边；无事件包、身份复制、恋人、交换、额外票权角色或其他高级角色。保留普通警长 1.5 票。角色最多一名。

政策 `awa_netease_crow_v1`：

- `ballotPolicy: initial_ballot_only`（默认）：只在次日首轮放逐计票加一；若因此进入 PK，PK 不再加票。
- `ballotPolicy: all_ballots`：次日每一轮放逐计票各加一，仅当前候选中的诅咒目标能获得附加票。此为显式 AWA 可选变体。
- `actionPolicy: optional`（默认）允许明确放弃；`required_when_legal` 在有合法目标时要求选择。无合法目标始终允许明确放弃。
- `selfTarget: false`（默认）禁止自选；`true` 允许自选。官方简卡未明确自选，本项显式可配。

## 行动、时钟与结算

1. 自第一夜起，存活乌鸦每夜在自身独立阶段选择一名当时存活玩家，或按政策明确放弃。必须经过真实请求窗口及网关；错误、缺失或晚失效响应严格失败，不随机代选。
2. 只有实际前一夜选择了同一目标才禁连选；中间一夜明确放弃则下一夜可重新选择该目标。历史以合法提交为准，不按仍存活目标或最近非空选择推导。
3. 提交后次日的效果属于已付款事实：乌鸦随后在本夜死亡不撤销诅咒；目标在白天投票前已死亡、没有放逐资格或不属于当前 PK 候选，则不加票，也不转移目标。目标绑定提交时的原生命、角色和阵营；同号复活、替换组件或改变身份均不继承。乌鸦仅允许同原生命的首次死亡保留效果，复活或身份替换不继承。
4. 附加票固定为 1，不是某位玩家的投票，不继承警徽 1.5 票，不制造 `vote_cast` 或伪造投票者。真实玩家弃票仍如实记录；当所有人弃票时，合法诅咒仍可使目标获得 1 票。
5. 警长选举、狼刀、任何非放逐流程完全不加票。次日未发生放逐（如自爆跳过白天）则本次效果到期，绝不延期到下一天。
6. 规则只改变每轮开票 tally；最高票、一次 PK、平票不出局、遗言、猎枪、最终判胜仍由现有所有者执行。首批不与定序王子复收票、诡术师目标映射等高级机制混用。

## 事实与可见性

- 夜间选择事实仅乌鸦本人及 God 可见，不向目标或狼队泄露；不提供身份／命中反馈。
- 实际附加票在该轮放逐开票前公布目标、票数与票轮，不公布乌鸦座位。公开票型仍只列真实玩家票，附加票有独立自然语言事件。
- 玩家状态只给本人脱离的政策、最近选择与历史数据；公共回放保留原事实 audience。中文与英文的 prompt、终端、Web 复盘均需覆盖。

## 验收与未支持范围

必须覆盖两种轮次政策、两种行动政策、自选开关、连续夜／隔夜放弃、乌鸦当夜死亡、目标提前死亡、全弃票、警长票权独立、PK 候选约束、晚响应与重复提交失败前缀、audience、严格复现及独立归档验算。公开 board/game 示例、20 seed 真引擎模拟、ZH/EN 测试通过并独立审查后才可标 implemented。

本卡不支持任意角色混搭、Scandalmonger 两票、可累积多夜诅咒、公开乌鸦身份或给被诅咒者预先通知等变体。

## 实现与回归边界

唯一运行所有者位于 `backend/src/features/crow/`；实际放逐流水线只调用具名加票端口，阶段管理器和死亡结算不增加逐角色分支。新提示通过本族 `custom` 值查询贡献实现，不扩大中央原生角色捕获。共享事实/自然语言分别由 game-contract、game-presentation 和 game-text 拥有；独立验算位于 `recording/verification/crow/`，不导入生产算法。

公开操作、中英文 LLM／ACP 入口和 God 教学归档见[乌鸦示例](../examples/crow/README.md)。回归覆盖各票政策与玩家受众、DTO 白名单、关闭墓碑、换席撤权及独立 verifier；整局、合成传输和逐帧结果分别验证，不外推任意组合或真实模型质量。
