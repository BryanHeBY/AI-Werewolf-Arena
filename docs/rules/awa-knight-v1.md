# AWA Knight 1.0.0 规则卡

awa_classic1.0.0角色扩展，ID `knight`，骑士／Knight；来源核验2026-10-08。与觉醒骑士的另一规则版本分别说明，不提前启用连续决斗或误伤双方死亡。

## knight

- 好人神职、好人获胜归属，不获狼队私有信息。默认一次决斗，只有本人看到机会状态。
- 存活且有机会时，可在本板启用的离散发言窗口执行 `duel(target_id,confirm=true)`；目标为其它当前存活玩家。可不行动，不通过null/错误动作消费机会。
- 按目标真实Camp判断：Wolf死亡（Duel），完整死亡链/警徽/判胜后若未终局直接入夜；非Wolf则目标存活、骑士死亡（DuelFailure），骑士有一次明确遗言，处理警徽/钩子/判胜后未终局继续原白天发言/投票。
- 目标查验伪装不改变真实Camp判定；third_party按非Wolf处理，只公开not_wolf，不额外揭露其第三方/具体牌。成功公开 `knight_duel {actorId,targetId,result: wolf|not_wolf}`确认骑士身份与此结果。
- Duel不授予猎人/狼王枪，不触发白狼王带人；DuelFailure是明确骑士失误原因，只有纯此原因且Day初批有遗言；成功被击败的狼及追加死亡无基础遗言。非决斗死亡不发动此技能。
- 机会在最终已采纳消费；非法/拒绝/取消/迟到/角色、资源或双方生命改变不消费。多个骑士同窗同时请求只取最低仍有效ID，未选者保留机会到下一窗口/日次。

## 窗口及配置

`roles.knight.enabledWindows`：before_speeches（已公开夜死/选举完，正常发言及方向选择之前）、between_speeches（每次正常发言后，含最后）、after_speeches（全部正常发言之后、进入Voting之前）；默认仅after_speeches，[]关闭。对应共用duel_window context/实际stage绑定，不能自由在Night/选举/遗言/Voting调用。

执行顺序为天亮自爆→发言前决斗、每次间隙自爆→间隙决斗、最后间隙处理完→发言后决斗→进入Voting自爆。between_speeches和after_speeches同时启用时最后边界是依次两个独立窗口，每窗最低有效ID一人，每名普通骑士总共一次，不是觉醒连续技能。同一发言间隙先处理已配置的狼自爆，再处理骑士；真实自爆中断后不发决斗请求。误伤并死亡的骑士不会再发普通发言/投票请求；原排定发言顺序继续跳过死者，徽章按基础策略转移。其它终局不能请求额外决斗/遗言/警长行动。

## 来源及AWA改编

[赛事组织者狼美骑士板](https://melbournemasters.org/setups/lang-mei-qi-shi)规定发言时翻牌，狼死亡入夜，误伤骑士遗言并继续发言；[官方站刊载的社群方案“孤独中的狼群”（正文2017-01-10）](https://langrensha.com/wanfa/tese/2017/10/17/26900_719112.html)描述一次机会及发言结束投票前发动，页面含征稿说明，不代表统一赛事规则。本AWA默认后者时点，并允许明确离散发言前/间隙替代真人随时插话。

[2026官方觉醒骑士](https://langrensha.com/news/activity/20260811/26906_1310699.html)有连续决斗、误伤双死等另一组规则，不用于普通骑士。基础自动徽章、真实阵营/查验标签分离、Duel禁枪、成功目标无遗言及完整链后判胜为本版本明确选择。狼美人 Duel 禁牵连按其规则卡处理，不能外推未注册角色。

## 必须验收

真实/伪装Camp，命中/误伤/目标不死及明确遗言、末神/末狼临界、徽章、旧狼自爆优先、三离散窗口/关闭、非法和撤权不消费、多骑士最小ID、正确语言/日次/本人资源、无隐藏牌信息、6/12人工完整局与SDK/ACP/混合通路、严格Tape/随机受限观察、主档/终端/前端/视频帧，独立三路交叉审查。
