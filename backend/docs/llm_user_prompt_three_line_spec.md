# LLM User Prompt 三行高密度规范

## 背景

为降低提示词漂移风险，行动前 `user prompt` 改为三行自然语言高密度格式。
该规范目标是减少上下文噪声，将失败归因更多收敛到模型能力本身，而非提示工程复杂度。

## 目标

1. 每次行动前 `user prompt` 固定为三行，不使用 `key=value` 结构。
2. 明确输出发言轮次状态文案：
   - `目前是你的发言轮次。`
   - `目前不是你的发言轮次。`
3. 保留最小可执行信息：
   - 当前阶段与子阶段
   - `mustAct` 强制行动要求
   - 可用工具列表
   - 工具参数提示

## 三行模板

```text
[上帝行动提示] 现在轮到你行动，当前处于{phase}阶段，子阶段是{stage}，{目前是你的发言轮次|目前不是你的发言轮次}。
{你本轮必须至少调用一次可用工具完成行动。|你本轮可以选择结束回合不行动。} 你当前可以使用的工具有：{toolList}。
工具参数提示：{toolArgHints}。请直接调用工具完成本轮行动。
```

## 规则说明

1. 发言轮次判定：
   - 若本轮可用工具包含 `speak` 或 `speak_to_wolves`，判定为“是你的发言轮次”。
   - 其他情况判定为“不是你的发言轮次”。
2. `mustAct` 文案：
   - `mustAct=true`：必须至少调用一次工具。
   - `mustAct=false`：可结束回合不行动（系统约束仍由 system prompt 决定）。
3. 保持 system prompt 现有硬约束不变（工具调用、禁止思维链、阶段职责等）。

## 验收标准

1. `LLM_IO` 中每次 `prompt_user` 为严格三行，且文案符合模板。
2. 发言阶段（白天发言/狼人夜聊）显示“目前是你的发言轮次”。
3. 非发言阶段（投票、查验、守护、用药等）显示“目前不是你的发言轮次”。
4. `build:v3` 与 `tests/v3` 全量通过。
